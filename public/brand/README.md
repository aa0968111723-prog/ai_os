# Aios 品牌資產

## 可直接使用

- `logo-aios-color-embedded.svg`：由使用者提供的 Aios Logo 裁切後建立，可直接用於 `<img src="/brand/logo-aios-color-embedded.svg">`。

## 來源與限制

本資產保留原始彩色立體外觀，並裁除大面積空白。由於目前 GitHub 連線只支援文字檔寫入，圖片以 WebP 資料內嵌於 SVG 中，並非重新描繪的向量 Logo。

後續 Issue #139 執行全站品牌替換時：

1. 先以此檔完成 `BrandLogo` 與主要介面替換。
2. 若能以一般 Git 上傳取得原始 PNG，再替換成原生 PNG／WebP 資產。
3. 不要自行改字樣、顏色順序或 Logo 造型。
