# Empty-state illustrations (Aios ribbon)

Place **square 512×512 PNG** files here (light background, matches ivory `--bg`):

| File | Use |
|------|-----|
| `empty-projects-sq-512.png` | 無專案／列表空 |
| `empty-messages-sq-512.png` | 無訊息／對話空 |
| `empty-media-sq-512.png` | 無媒體／素材庫空 |
| `ribbon-mark-sq-512.png` | 通用緞帶裝飾 |

Paths are declared in `client/src/illustrations.ts` and rendered via `EmptyIllustration`.

**Do not** put UI chrome icons here — those stay in `Icon.tsx` (Lucide).
**Do not** replace `client/public/brand/*` logos in this folder.
