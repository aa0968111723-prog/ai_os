# 首頁 (Login Page) 實際顯示內容紀錄

本文件記錄 Aios 首頁（未登入狀態下的登入頁面）的實際顯示內容、區塊、按鈕與導覽結構。
資料來源：實體網站文字擷取與 `LoginPage.tsx` 原始碼。

## 1. 頁面區塊 (Sections)

首頁採用全螢幕滿版置中佈局（`100dvh`），主要包含以下區塊：
*   **全域背景**：帶有環境光漸層的暖灰色底（`--bg`）。
*   **中央登入卡片 (`.login-card`)**：包含所有登入互動元素。
    *   **品牌展示區**：包含 Logo 與標語。
    *   **表單輸入區**：Email 與密碼輸入框。
    *   **提示訊息區**：關於邀請制的說明文字。
    *   **PWA 安裝橫幅區**：提供安裝為獨立應用程式的提示（若瀏覽器支援）。

## 2. 實際顯示內容 (Content)

*   **品牌標語**：「AI 創作作業系統」
*   **品牌名稱**：「Aios」
*   **表單標籤**：「Email」、「密碼」
*   **輸入框預設文字 (Placeholder)**：「you@example.com」
*   **底部提示文案**：「帳號採邀請制——請向你的組長或管理員索取邀請連結。忘記密碼請找管理員重設。」

## 3. 互動按鈕 (Buttons)

*   **「顯示」按鈕**：位於密碼輸入框旁，用於切換密碼的明碼/遮蔽顯示狀態。
*   **「登入」按鈕**：主動作按鈕（Primary CTA），寬度 100%，點擊後觸發登入驗證。若處於載入中狀態，會顯示旋轉圖示與「登入中…」。

## 4. 導覽 (Navigation)

*   **無全域導覽列**：由於是未登入的到達頁（Landing/Login Page），為保持使用者專注於登入動作，頁面上**沒有**頂部導覽列（Topbar）、側邊欄或底部導覽列。
*   **無外部連結**：目前頁面上沒有跳轉至其他頁面（如註冊、忘記密碼獨立頁面）的超連結，所有操作皆集中於單一卡片內。
