# 【母版系列】週更開示 60 秒 — 組員操作卡

> 一頁看完。口訣：**複製 → 填 4 格 → 依 5 段生成 → 排分鏡 → 送審**

---

## 1. 開新的一集

1. 找到專案 `【母版】週更開示60秒`  
2. **複製**專案  
3. 改名：`週更開示60秒｜日期｜主題`  

---

## 2. 只填這 4 格（寫在專案筆記）

| 必填 | 說明 |
|------|------|
| 本集主題 | 一句話 |
| 必留原句／出處 | 有開示原文就貼上；沒有寫「無」 |
| 本集禁忌 | 例如不提某事、不用某類畫面 |
| 截止日期 | 精修／上架日 |

其餘（60 秒、直式、5 段結構）**全部跟母版，不要自己改。**

---

## 3. 依固定 5 段產出

1. 0–5 秒　開場鉤子  
2. 5–15 秒　一句核心（大字幕）  
3. 15–40 秒　說明兩點  
4. 40–55 秒　例子或提醒  
5. 55–60 秒　收束  

每一段：在 **AI 工作** 生成 → 可用的加入分鏡 → 排好順序。

---

## 4. 送審前自查

- [ ] 掛在「本集專案」，不是母版  
- [ ] 5 段都有內容  
- [ ] 看過預估點數  
- [ ] 原句／禁忌有遵守  

---

## 5. 送審後

- 等組長 **通過／退回**  
- 退回：依原因改，不要重改整套結構  
- 通過：下載／交付 → 進剪輯軟體精修字幕與卡點  

---

## 不要做

- 改母版結構  
- 略過送審  
- 共用別人帳號  
- 未通過就當定稿對外
