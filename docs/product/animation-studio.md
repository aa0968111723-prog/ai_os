# 動畫創作室（Animation Studio）

> 路由：`/studio`（挑專案）、`/studio/:projectId`（創作室本體）
> 程式：`client/src/features/animation-studio/`、`client/src/pages/AnimationStudioPage.tsx`

## 這一頁在解什麼

分鏡的第一版幾乎都是手畫的——構圖、鏡位、人物走位在腦裡是圖不是字。
站內原本只有「文字提示詞 → 生成」這條路，於是那張草圖只能畫在紙上、拍照、上傳，
再用文字把它重講一次。創作室把這一段收進站內：

**手繪大白板**（畫）→ **順序分鏡表**（排）→ **AI 協作欄**（把畫面變成文字、把手稿變成分鏡畫面）

## 三個區塊與兩種版面

| 區塊 | 桌機 | 手機輕量版（≤820px 或觸控 ≤1100px） |
| --- | --- | --- |
| 手繪大白板 | 中央，常駐 | 中央，常駐（其餘面板讓位） |
| 筆刷櫃 | 左側直欄，含手感微調 | 底部橫向 dock，只留粗細／濃度／顏色 |
| 順序分鏡表 | 底部橫向軌道，可拖曳重排 | 貼底 sheet（點「分鏡」叫出），只用箭頭重排 |
| AI 協作欄 | 右欄（<1180px 先收起） | 貼底 sheet（點「AI」叫出） |

版面決策的單一真相是 `studioLayout.ts` 的 `resolveStudioLayout()`。
**輕量版不只是把面板藏起來**，它同時降低白板的實際成本：

| 預算 | 桌機 | 輕量版 |
| --- | --- | --- |
| 筆畫上限 | 2000 | 400 |
| 復原步數 | 60 | 20 |
| 匯出長邊 | 2048px | 1280px |
| 渲染 DPR | ≤2 | ≤2 |

（DPR 3 的手機畫滿版白板是四倍像素成本；沒有筆畫上限的話，低階機愈畫愈頓。）

## 白板怎麼運作

三層堆疊，這是「描圖」與「橡皮擦」能同時成立的原因：

```
① 紙面（白色方框，CSS）
② 參考圖 <img>（這一鏡目前的畫面，可切換顯示）
③ 筆畫 canvas（透明）＋ live canvas（正在畫的那一筆）
```

橡皮擦用 `destination-out` 只挖掉第三層，露出紙面與參考圖；
若把參考圖畫進 canvas，擦線條會把描圖底稿一起擦掉。

正在畫的一筆只重畫它自己（live 層），所以白板上已有幾百筆時，筆跡延遲仍是常數。
橡皮擦例外——它要挖的是已提交那一層，所以直接畫在 base 上。

### 筆刷

六支內建（鉛筆／簽字筆／毛筆／麥克筆／噴槍／橡皮擦），參數化的筆跡數學全在
`brushes.ts`：壓力→線寬、速度→飛白、收筆漸細、顆粒抖動、等距取樣。
顆粒與噴濺是**決定性**的（由筆畫 id ＋ 點序號推導），否則每次縮放重繪畫面都會抖。

沒有壓感的裝置一律以 0.5 計（`normalizePressure`）——直接用 `pressure=0` 會畫出
一條看不見的線，是「我畫了但沒東西」最常見的成因。滑鼠與手指改用速度近似壓力。

### 收錄筆刷

心智模型一條：**內建筆刷是範本，收藏的筆刷是你的**（規則在 `brushCollection.ts`）。

- 調整內建筆刷 → 只影響這次落筆，換一支再換回來仍是原本的手感
- 收錄 → 存成一支屬於你的筆（上限 24 支）
- 調整自己的筆 → 直接記住

## 資料流

| 動作 | 走哪支既有能力 |
| --- | --- |
| 讀分鏡 | `scenes.listByProject` |
| 加一鏡／重排／改欄位 | `scenes.addDraft`／`scenes.move`／`scenes.reorder`／`scenes.update` |
| 白板存成這一鏡的畫面 | `/api/upload`（進素材庫）→ `scenes.setVisualFromAsset` |
| AI 給畫面建議 | `director.suggest`（可填進這一鏡或另存成新鏡） |
| 貼腳本拆整份分鏡 | `director.splitScript` |

**沒有新增任何後端端點、沒有 migration。**

## 草稿存在哪裡

白板草稿存 localStorage，每個「專案 × 分鏡」一份（`_free` 是還沒選分鏡時的自由塗鴉）。
理由與代價：

- 塗鴉階段不該打擾團隊素材庫，也不該讓每一筆都等網路
- 代價是**綁裝置**：手機畫的不會出現在電腦上，UI 有明講
- 空間滿了會先清掉同專案其他鏡的草稿再試一次，仍失敗就顯示「本機草稿空間已滿」，
  絕不默默丟掉（畫面上還在、其實沒存到，是最傷的失敗模式）

存檔在停筆 600ms 後寫入，離開創作室時再補存一次。
切換分鏡時「舊分鏡 id 配上新白板」這個經典覆蓋 bug 由 `useBoardSession.test.ts` 盯著。

## 已知界線

- 草稿不跨裝置同步（見上）。要跨裝置就是「存成這一鏡的畫面」。
- 白板是筆畫向量，不支援匯入圖層或貼圖；描圖底稿只有「這一鏡目前的畫面」。
- 匯出 PNG 只含紙面與筆畫，**不含**描圖底稿——那張是拿來描的，烘進去會分不清哪張是手稿。
