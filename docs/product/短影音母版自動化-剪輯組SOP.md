# 短影音母版自動化 · 剪輯組 SOP

> 對象：剪輯組組長與組員  
> 原則：**先固定一條系列，只自動化重複的 80%**；開示合規與成片定稿不交給全自動。  
> 不談程式，只談流程與站內操作對照。

---

## 0. 為什麼要母版

相同結構的短影音（例如每週 60 秒開示），不適合每集從零想流程。  
**母版 = 固定骨架**；每集只改「主題變數」。

```
固定骨架 + 每集變數 → 自動／半自動備料 → 組長審 → 剪輯軟體精修
```

---

## 1. 三期節奏（不要一次上滿）

| 期程 | 目標 | 自動化什麼 | 人做什麼 |
|------|------|------------|----------|
| **第 1 期（先做）** | 母版可複製 | 專案複製、筆記骨架、分鏡空殼、檢查清單 | 填本集主題、審批、精修 |
| **第 2 期** | 一鍵跑完備料 | 文案→分鏡→圖／短片／旁白串成計畫 | 只審待審、退回原因 |
| **第 3 期** | 週更半自動 | 主題佇列批次、點數上限、單鏡重跑 | 週初定題、週中批次審 |

驗收第 1 期樣片通過後，再進第 2 期；連續多集穩定後再談第 3 期。

---

## 2. 第 1 期：建母版（只做一次）

### 2.1 選系列

挑**最常做、結構最穩**的一條，例如：`週更開示 60 秒`（直式）。

### 2.2 母版專案

- 專案名稱：`【母版】週更開示60秒`
- 專案筆記建議寫死：

| 欄位 | 內容 |
|------|------|
| 時長 | 約 60 秒 |
| 比例 | 直式 9:16 |
| 結構 | 見下方 5 段 |
| 畫面風格 | 簡潔、字幕清楚 |
| 禁忌 | 不斷章取義、不戲謔開示、不用爭議人物畫面 |
| 交付 | 站內審過 → 進剪映／Premiere／FCP 精修 |

### 2.3 分鏡骨架（5 段）

1. **0–5 秒** 開場鉤子  
2. **5–15 秒** 一句核心（大字幕）  
3. **15–40 秒** 說明兩點  
4. **40–55 秒** 例子或提醒  
5. **55–60 秒** 收束  

### 2.4 每集只填 4 變數

1. 本集主題  
2. 必留原句／出處  
3. 本集禁忌  
4. 截止日期  

### 2.5 每集標準流程

1. 複製母版專案 → 改名 `週更開示60秒｜YYYY-MM-DD｜主題`  
2. 填 4 變數進筆記  
3. 依 5 段在「AI 工作」產出並排分鏡  
4. 送審  
5. 通過後交付 → 剪輯軟體精修  

### 2.6 組長每集只做 3 件事

1. 變數是否填齊、有無違禁忌  
2. 結構是否仍是 5 段  
3. 通過／退回（退回寫一句原因）  

### 2.7 第 1 期驗收（樣片 1 集）

- [ ] 組員只靠專案筆記做得完  
- [ ] 產出掛在正確專案  
- [ ] 審一次能決定過／退  
- [ ] 能帶走精修  
- [ ] 點數在可接受範圍  

---

## 3. 第 2 期：創作代理計畫（備料串鏈）

詳見同目錄：`短影音母版-創作代理計畫.md`。

重點：

- 成功條件寫死（5 段素材＋送審）  
- 超點數門檻必須待審  
- 退回用固定標籤，只重做被點名步驟  
- **禁止**未審定稿、改母版本體、略過估點  

---

## 4. 第 3 期：週更半自動（可選）

- 週一主題佇列 3～5 則 → 各從母版開案 → 限併發跑計畫  
- 本週系列點數上限  
- 單鏡重跑，不整集重跑  
- **不做**：無審核自動上架、多平台矩陣日更  

---

## 5. 分工邊界

| 可自動化 | 必須人工 | 剪輯軟體 |
|----------|----------|----------|
| 複製母版、填空文案 | 主題是否合宜 | 精剪、卡點 |
| 分鏡骨架、批次備料 | 開示是否斷章 | 字幕細調 |
| 估點、送審、交付包 | 通過／退回 | 混音、輸出上架 |

---

## 6. 母版維護

| 情況 | 做法 |
|------|------|
| 只改本集主題 | 複製母版，改變數 |
| 全系列改風格／時長 | 改母版並公告 |
| 單集特例 | 該集註明偏離母版，不改母版 |
