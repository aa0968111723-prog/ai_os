# 統一專案、資料來源與 AI 介面調整

## 目標

將 AI Director OS 從「多個平行工具」收斂為「以專案為中心的 AI 創作工作空間」。

使用者只需要理解以下四個概念：

1. **工作空間**：目前是個人、組別或團隊情境。
2. **專案**：目標、資料、創作、任務、審核與交付的主要容器。
3. **知識與資料**：AI 可以參考或寫入的文件、資料表與外部來源。
4. **AI 創作助手**：主要互動入口，負責回答、創作、規劃與提出執行方案。

底層的模型、代理、工作流、MCP、API 與權限機制繼續保留，但不要求一般使用者先理解工程名詞。

## 本 PR 完成的第一階段

### 1. 統一專案 AI 名稱

使用者介面改用：

- `專案 AI 代理系統` → `AI 創作助手`
- `代理執行` → `AI 執行計畫`

行為不變：

- 單步寫入仍需使用者確認。
- 多步驟計畫仍需核准。
- 點數、ACL、背景執行、停止與重試機制不變。

### 2. 工作流改為製作範本

使用者介面改用：

- `工作流` → `製作範本`
- `執行工作流` → `執行製作範本`

產品定義：

- **製作範本**：步驟固定、可重複使用的自動流程。
- **AI 執行計畫**：AI 依目標動態規劃、需要核准的多步驟執行。

底層 `workflows` procedure、資料表與 runner 名稱本階段不變，避免大範圍遷移。

### 3. 整合服務改為資料來源

`/integrations` 頁面改用「連接的資料來源」定位，並加入明確三步驟：

1. 連接 Google、Notion 或外部 API。
2. 前往「知識與資料」選擇要匯入的內容。
3. 將內容加入專案，交給 AI 創作助手引用與分析。

本階段不自動讀取整個外部帳號，也不改 OAuth、token、加密或 API 安全限制。

## 保持相容的項目

本 PR 不修改：

- `/integrations`、`/databases` 等既有 URL。
- tRPC procedure 名稱。
- `workflowRuns`、`agentRuns`、資料庫與權限 schema。
- Google Drive、Notion、API 憑證存放方式。
- 點數扣除、核准、ACL、冪等與背景 runner。
- MCP 對外工具契約。

## 後續實作階段

### Phase 2：知識與資料入口

- 將「資料庫」介面名稱收斂為「知識與資料」。
- 首頁與專案內提供統一「加入資料」入口。
- 支援本機上傳、Google、Notion、網址、API、既有資料表。
- 在專案內匯入時，自動綁定目前專案與合理預設權限。

### Phase 3：匯入後 AI 分析

形成完整流程：

`匯入 → 解析 → 可讀狀態 → 綁定專案 → AI 分析 → 引用證據 → 轉成任務／筆記／分鏡／執行計畫`

匯入完成畫面至少顯示：

- AI 是否可讀。
- 綁定到哪個專案。
- AI 發現的摘要、缺漏或風險。
- 可以轉換成哪些下一步。

### Phase 4：專案固定 AI 入口

- AI 創作助手固定出現在專案工作區。
- 助手自動取得目前專案、頁面、文件與選取項目上下文。
- 一般使用者不需要選擇「代理、工作流或生成模式」。

### Phase 5：統一 Tool Registry

建立一致的工具契約：

- 名稱與用途。
- 輸入與輸出 schema。
- 個人、專案、組別、團隊 scope。
- read／write 模式。
- 是否需要核准。
- 點數類型。
- 冪等與重試策略。

現有 Router、MCP、Assistant、Agent Core 與 Runner 逐步改為同一組工具的 adapter。

### Phase 6：事件、記憶與評估

完整代理循環：

`Observe → Understand → Plan → Policy Check → Approval → Execute → Evaluate → Save Memory → Continue／Replan／Finish`

需要補齊：

- 持久化對話與任務記憶。
- 文件匯入、審核結果、排程與外部同步事件。
- 執行結果評估與重新規劃。
- 等待條件、依賴、平行步驟與失敗恢復。

## 驗收方向

### 第一階段

- 使用者在專案內只看到「AI 創作助手」與「AI 執行計畫」。
- 固定多步驟流程以「製作範本」呈現。
- Google、Notion、API 頁面清楚說明連接後的下一步。
- 不破壞現有 API、權限、扣點與背景執行。

### 最終完成定義

使用者可以沿著單一路徑完成工作：

`進入專案 → 加入資料 → 告訴 AI 想完成什麼 → 確認執行 → 查看成果與下一步`
