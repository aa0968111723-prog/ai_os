## 三、已驗證為健全（無缺陷）之處

- 密碼雜湊（bcrypt cost 10）＋登入計時側通道防護（dummy-hash 等成本比對）、session/invite/MCP 金鑰一律存 SHA-256。
- `reserveQuota`：per-user／per-group／全域三層 advisory xact lock 依序取用、單一交易內完成，**無預算 TOCTOU**；CAS 防重複退款/重複入庫。
- CSV 公式注入（`=,+,-,@`）匯出時正確中和、匯入無損還原；CSV 解析器對引號/內嵌換行/BOM/星芒 unicode 皆處理。
- AI 存取等級（none/read/write）在 REST 與所有 MCP 資料庫工具一致套用；path traversal（UUID 檔名＋`absPathOf` 包含性檢查）不可達。
- 審批狀態機以 per-scene advisory lock＋`status='pending'` CAS 收斂 approve/reject 競態與版本遞增。
- Realtime 於升級時做專案↔組授權＋Origin 白名單＋定期重驗，無跨租戶外洩。
- 前端無 `dangerouslySetInnerHTML`/`innerHTML`；計時器/interval/WebSocket 皆於 effect 清理；路由守衛（`/admin`/`/options`/`/logs`）前後端一致。
- LLM JSON 解析全數 try/catch 或 `safeParse` 兜底，模型亂吐不致崩潰。
