## 📊 測試維度

每次測試攻堅涵蓋以下維度：

1. **功能驗證** — 40 個 AI 能力逐一驗證
2. **API 測試** — 全端點測試 + edge cases + SQLi/XSS 防護
3. **源碼審查** — 安全審計（SQLi、XSS、ACL、CSRF、敏感資訊）
4. **效能測試** — 回應時間基準 + 壓力測試 + 資源使用
5. **工具鏈測試** — LLM 工具迴圈 + JSON 解析 + 容錯機制
6. **UX 審查** — 桌面/手機全情境 + 無障礙 + 視覺一致性
7. **行為分析** — 使用者路徑 + 流失點 + 意圖分類準確度
8. **安全滲透** — billing 漏洞 + injection + 權限繞過
9. **整合測試** — 跨功能整合 + 回歸測試
10. **真實情境** — 30+ 種日常查詢 + 新使用者 onboarding
