# 外部 AI 成品帶進站內（路線 C）

回應需求「夥伴自己訂閱了 Gemini／ChatGPT，或用自己的工具生成，要怎麼串到這個網站？」

夥伴問「怎麼串接」時，十之八九想做的其實是**把在別處做好的東西帶進站內繼續用**——
不是要本站去呼叫他的帳號。這條路**不需要任何金鑰、不需要技術背景、今天就能用**，
是給非工程夥伴的預設答案。

> **先講清楚一件事：訂閱不能串接。**
> ChatGPT Plus／Pro、Gemini Advanced 這類**月費訂閱**只授權本人在官方 App／網頁裡使用，
> 沒有附帶 API 存取權。要讓程式（本站）代為呼叫，必須另外去 platform.openai.com 或
> Google AI Studio 申請 **API Key**，那是**另一個按用量計費的錢包**，跟月費完全分開。
> 所以「我有訂閱」≠「可以串進來」——請先跟夥伴確認他要的是哪一件事：
>
> | 他想做的事 | 走哪一條 |
> | --- | --- |
> | 把在 ChatGPT／Gemini 做好的稿子、圖、影片帶進站內用 | **本文（路線 C）** |
> | 用自己的額度在站內生成、不扣平台點數 | 路線 A：整合連接頁 →「個人 AI 金鑰（fal.ai）」 |
> | 在自己的 Claude／ChatGPT 裡直接操作站上的專案 | 路線 B：頂欄選單 →「接上外部 AI」（`/mcp`） |

---

## 四種帶進來的方式

| 方式 | 適合什麼 | 在哪裡做 | 要不要設定 |
| --- | --- | --- | --- |
| **1. 直接上傳素材庫** | 圖、影片、音檔、成品檔 | 專案頁 → 素材庫 →「上傳」 | 不用 |
| **2. 手機「分享」進來** | 在手機的 AI App 裡剛做好的東西 | 手機分享選單 → 選本站 | 裝成手機捷徑（PWA）即可 |
| **3. 資料庫文件** | 文字稿、逐字稿、表格、PDF——**要讓 AI 讀得到** | 知識與資料 → 資料庫 → 上傳／從網址匯入 | 不用 |
| **4. 連自己的雲端** | 東西已經在自己的 Google 雲端／Notion／自家系統 | 整合連接（`/integrations`） | 一次性授權 |

---

## 1. 直接上傳素材庫

最短路徑。在 ChatGPT／Gemini／Midjourney／剪映——任何工具——做好的檔案，存到電腦後：

1. 打開專案 → **素材庫** 分頁 → 按「上傳」（或直接把檔案拖進去）
2. 上傳完就是一般素材：可以加進分鏡、當成生成的**參考圖／來源素材**、進交付包

**這件事很重要**：上傳進來的素材可以直接當**生成來源**。也就是說，夥伴可以在自己訂閱的
Gemini 裡出一張滿意的圖，上傳進來，再用站內的模型接著做圖生影、去背、放大、對嘴——
外面的訂閱負責前半段，站內負責後半段，兩邊都不浪費。

| 規格 | 值 | 出處 |
| --- | --- | --- |
| 單檔上限 | 200MB（`ASSET_MAX_MB` 可調） | `server/services/storage.ts:41` |
| 存放位置 | 伺服器持久 Volume 或物件儲存，網址永久有效 | `client/src/components/AssetLibrary.tsx:50` |
| 型別檢查 | **驗檔頭簽名**，不只信副檔名與宣稱 MIME | `server/index.ts` `/api/upload` |

## 2. 手機「分享」進來

站台是 PWA，登記了 Web Share Target（`client/public/manifest.webmanifest`）。把網站加到手機主畫面後：

1. 在手機的 ChatGPT／Gemini App 裡按**分享**
2. 分享選單挑本站
3. 開啟的頁面選要放進哪個專案 → 存進素材庫

適合「在手機上跟 AI 聊出一段文案／一張圖，順手丟回專案」的情境，省掉「存檔 → 開電腦 → 上傳」。

## 3. 資料庫文件（要讓 AI 讀得到就走這條）

素材庫收的是「成品」；**要讓站內 AI 讀進去當上下文的文字**，要放「知識與資料 → 資料庫 → 文件」。
上傳或匯入後系統會**自動抽出純文字**，之後團隊助手、AI 代理、MCP 工具都讀得到。

**兩種進來的方式：**

- **上傳檔案**：資料庫的文件區直接上傳
- **從網址匯入**：貼連結即可——
  - Google 文件／試算表／簡報／雲端硬碟（公開連結；私有連結要先做第 4 步）
  - Notion 頁面與資料庫（需站方 `NOTION_TOKEN` 或自己的個人 token）
  - 一般網頁（抓 HTML 轉純文字）
  - 匯入後可隨時按「重新整理」重抓最新版

**會自動抽文字的格式**：`txt`／`md`／`csv`／`tsv`／`json`／`html`／`srt`／`vtt`／**PDF**／**DOCX**。
其他格式（`doc`／`xls`／`ppt`／`epub`／壓縮檔／圖片／影音）**收得下但不抽字**——
會存著給人下載，AI 讀不到內容。要讓 AI 讀，請先另存成上面那幾種。

| 規格 | 值 | 出處 |
| --- | --- | --- |
| 網址匯入抓取上限 | 25MB | `server/services/databaseFiles.ts:21` |
| 抽字的原檔上限 | 30MB（超過只存檔不抽字） | `server/services/databaseFiles.ts:23` |
| 單檔抽出文字上限 | 300,000 字（夠放整本逐字稿） | `server/services/databaseFiles.ts:19` |
| 每人儲存配額 | 預設 5GB（管理員可在設定調整，0＝不限） | `server/services/databaseFiles.ts:25` |

## 4. 連自己的雲端（東西已經在別處的話）

如果夥伴的成品本來就存在自己的 Google 雲端或 Notion，不必先下載再上傳——
到 **整合連接**（使用者選單 → 工作 →「整合連接」，`/integrations`）連一次，之後貼**私有連結**就能直接匯入：

| 整合 | 他要做什麼 | 連上後 |
| --- | --- | --- |
| **Google 雲端硬碟** | 點「連結 Google 雲端」走一次 OAuth（**只授權讀取**） | 貼私有的文件／試算表／簡報／雲端檔連結就能匯入，不必改成「知道連結的人都能看」 |
| **Notion** | notion.so/my-integrations 建整合 → 貼 Internal Integration Secret → 把頁面 Connections 給該整合 | 貼自己的 Notion 頁面連結即可匯入 |
| **外部資料庫／API** | 登記「名稱＋基底網址＋認證標頭」（Airtable、Supabase、自架服務……任何回 JSON/CSV 的 https 端點） | 資料庫匯入面板出現「從外部連接抓」，選連接、填路徑、一鍵抓進來 |

憑證一律 AES-256-GCM 加密存放、**永不回顯**，只綁本人、隨時可移除。
完整資安設計與站方一次性設定見 [整合連接](整合連接.md)。

> 外部 API 目前只支援**拉取（GET）**。反向「把站內資料推出去」請用 REST API v1
> ＋個人連線金鑰（路線 B）。

## 帶進來之後能做什麼

1. **當生成來源**：素材庫的圖／影／音可以直接選為生成的來源輸入（圖生圖、圖生影、對嘴、去背、放大）
2. **當 AI 的上下文**：資料庫文件的純文字會被團隊助手與 AI 代理讀到，寫文案／拆分鏡時自動引用
3. **進分鏡與交付包**：素材可加進分鏡排序，最後隨交付包一起輸出（含剪輯軟體時間軸檔）
4. **外部 AI 也讀得到**：透過 MCP（路線 B），夥伴在自己的 Claude 裡也能查、能讀這些文件

> **內容分寸提醒**：外部 AI 生成的稿件與引用一律視為**草稿建議**，
> 對外發布前須經組長審核（見 [使用條款](使用條款.md)）。這條不因為「是 AI 產的」而放寬。

## 常見問題

**Q：我付了 ChatGPT Plus，為什麼不能直接接？**
訂閱賣的是「你本人在官方介面用」的權利，沒有給第三方程式呼叫的通道。要程式串接得另外開 API Key，
另外計費。這不是本站的限制，是各家 AI 服務共同的設計。

**Q：那我想用自己的錢在站內生成怎麼辦？**
走路線 A：辦一把 fal.ai 金鑰貼到整合連接頁。站內的 Gemini、GPT、Claude 系模型本來就是透過 fal 的
`any-llm` 路由在跑（見 [fal 生態研究](fal生態研究.md)），所以**一把 fal 金鑰就同時涵蓋圖／影／音／文與各家大模型**，
不必每家各開一個帳號、各記一筆帳。

**Q：檔案上傳了，AI 卻說看不到內容？**
八成是放錯地方或格式不對——素材庫是給人看與給生成當來源的，要讓 AI 讀文字內容請放「資料庫 → 文件」，
且格式要在會抽字的清單內（見上面第 3 節）。

**Q：我的東西很大／很多，會不會爆？**
單檔素材 200MB、網址匯入 25MB、每人文件配額預設 5GB。超過請先分割或壓縮畫質；配額不夠找管理員調。

**Q：連了 Google 雲端，站方是不是就看得到我全部檔案？**
授權範圍是 `drive.readonly` 且**綁你個人**——只有你自己在匯入時才會用到你的授權，其他人看不到、
也不會自動同步；隨時可以在整合連接頁中斷（會盡力向 Google 撤銷授權）。

## 檔案地圖

| 檔案 | 角色 |
| --- | --- |
| `server/index.ts` → `POST /api/upload` | 素材上傳（multipart、檔頭簽名驗證、200MB 上限） |
| `client/src/components/AssetLibrary.tsx` | 素材庫上傳與瀏覽 UI |
| `client/src/pages/ShareTargetPage.tsx`＋`client/public/manifest.webmanifest` | 手機分享進站 → 存進專案素材庫 |
| `server/services/databaseFiles.ts` | 文件層：文字抽取、網址匯入、配額與 SSRF 守門 |
| `server/routers/databases.ts` → `importUrl`／`refreshFile` | 網址匯入與重新整理（優先用個人憑證，失敗退回公開路徑） |
| `client/src/pages/DatabasesPage.tsx` | 資料庫頁：文件上傳、匯入面板、「從外部連接抓」 |
| `client/src/pages/IntegrationsPage.tsx` | 整合連接頁（Google／Notion／Adobe／外部 API／個人 AI 金鑰） |
| `server/services/integrations.ts` | 憑證加解密、OAuth state、Drive 抓檔、外部 API 同源抓取 |
| `server/services/userAiKeys.ts`／`byokBilling.ts` | 路線 A：個人 fal 金鑰與雙軌計費 |
| `client/src/pages/McpPage.tsx` | 路線 B：接上外部 AI（MCP 個人金鑰） |
