# AI 創作工作台｜第一階段整合規格

## 目的

將目前分散的 AI 助手、直接生成、製作範本與 AI 執行計畫，對使用者收斂成一套「AI 創作工作台」。

這一階段只調整資訊架構與操作入口，不改動既有後端契約。

## 使用者只需要理解的四種開始方式

1. **問 AI**：問答、發想、拆分鏡、查專案資料。
2. **直接生成**：圖片、影片、聲音與文字生成。
3. **製作範本**：依固定步驟一次完成多個生成環節。
4. **執行計畫**：將多步驟目標整理成可檢查、可估點、可核准的背景任務。

## 可連動的專案系統

工作台提供明確入口連回：

- 專案設定與世界觀
- 專案知識
- 專案資料來源與資料表
- 素材庫
- 分鏡與交付

這些入口仍使用既有頁面錨點，不新增路由或重複資料。

## 相容性原則

本 PR 不修改：

- URL 與頁面路由
- tRPC procedure 名稱
- 資料庫 schema
- MCP 工具名稱
- 生成與點數扣除邏輯
- 審核與權限規則
- Agent Runner 與背景執行流程

內部仍可保留 `agent`、`workflow`、`generation` 等技術名稱；使用者介面統一由工作台呈現。

## 第一階段驗收

- 專案頁只需先看到「AI 創作工作台」即可理解主要 AI 能力。
- 工作台可快速前往問 AI、直接生成、製作範本與執行計畫。
- 工作台可快速回到知識、資料來源、素材與分鏡。
- 既有執行中與待核准數量維持顯示。
- 點擊「執行計畫」時會自動展開既有執行區。
- 收合工作台不會卸載助手或中斷背景任務。

## 後續階段

### 第二階段：統一任務清單

由後端聚合 `generations`、`workflow runs` 與 `agent runs`，前端只顯示一份 AI 任務清單。

### 第三階段：統一成果中心

將生成結果、素材、文件、分鏡與報告統一成可追蹤的創作成果。

### 第四階段：統一意圖入口

新增一個意圖控制層，判斷使用者要求屬於問答、單次生成、製作範本或多步驟執行。

### 第五階段：跨系統工具層

讓助手、MCP、製作範本與背景執行器共用同一套工具註冊、權限、點數、核准與稽核規則。
