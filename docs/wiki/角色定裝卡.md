# 角色定裝卡

> 跨鏡頭鎖定同一張臉、同一套服裝。建卡一次，生成時勾選，系統自動把外觀寫進提示詞。

## 什麼時候用

- 主角／配角要在多個分鏡、多集內容裡「長得一樣」
- 不想每次手打「紅傘、米白外套…」
- 希望 AI 導演／助手也知道角色個性（但不把個性畫進畫面）

## 怎麼用（最短路徑）

1. 開專案 → **角色定裝**
2. **新增角色定裝**：填「角色名」+「外觀」（越具體越一致）
3. 選填：個性／備註、定裝參考圖
4. 建立後會**自動勾選**（未滿 6 個時）
5. 到生成台出圖／分鏡就地生成／工作流——勾選的角色會自動帶入

## 欄位怎麼填

| 欄位 | 會進畫面生成？ | 建議 |
|------|----------------|------|
| 角色名 | 是（當標籤） | 短、好認，避免同名 |
| 外觀 | **是** | 臉／髮／服裝／配飾；關鍵視覺詞優先放前面 |
| 個性・備註 | **否** | 語氣、關係、Do/Don't，給導演／助手 |
| 參考圖 | 選填 | 素材庫綁定；比對與圖生圖更有依據 |

> 外觀過長時，注入生成的段落會自動截短。把最重要的外觀特徵寫在前面。

## 上限（前後端一致）

| 項目 | 上限 |
|------|------|
| 單次生成帶入角色 | **6** |
| 每專案角色卡 | **50** |
| 角色名 | 40 字 |
| 外觀 | 1000 字 |
| 個性 | 1000 字 |

勾選達 6 時，其餘卡的「生成時帶入」會禁用並提示先取消其他勾選。

## 與世界觀的差別

| | 世界觀 | 角色定裝 |
|--|--------|----------|
| 管什麼 | 調性、主軸、風格、禁忌 | **單一角色的外觀錨點** |
| 注入時機 | 專案級，幾乎每次視覺生成 | **你勾選的卡**才注入 |
| 建議 | 寫整體氛圍 | 寫可畫出來的外觀細節 |

注入順序（視覺）：**世界觀 → 角色定裝 → 場景設定 → 你的提示詞**

## 參考圖進回收桶

- 縮圖會消失，但綁定可能仍在
- 卡上會標示「參考圖已在回收桶」
- 可 **清除綁定**，或先到回收桶還原素材再重設

## 失敗重試

生成失敗後按「以相同設定重試」會**保留**當次勾選的角色／場景錨點，不會默默變成無定裝版本。
