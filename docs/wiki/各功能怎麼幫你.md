## 1. 頂欄（隨時都在）⭐

| 功能 | 幫你什麼 | 何時用 |
|------|----------|--------|
| **組別切換** | 多組時切換「現在在哪個組的上下文」 | 跨組創作／審批前先確認組別 |
| **剩餘點數** ⭐ | 一眼看還能生多少；滑上看週／日與最緊額度 | 出圖／出片前 |
| **待辦鈴鐺** ⭐ | 分鏡待審、生成待核筆數，點進專案 | 組長每天；組員看自己有沒有被擋 |
| **誰在線** ⭐ | 不必進私訊就看夥伴上線／剛離開 | 想找人對稿、等審核前 |
| **私訊** ⭐ | 一對一討論、標注專案物件、傳檔 | 比留言更適合「兩人對齊」 |
| **筆記排程** | 會議、截稿、待辦上日曆；標題 @人 | 週會、審稿日 |
| **資料庫** | 你們的表格／清單（器材、名單…） | 非「做片主軸」但支援企劃 |
| **帳號選單** | 說明、模型指南、安裝 App、通知、下載文件、管理 | 設定與求助 |

## 4. AI 創作工作台 🎬⭐

專案裡**主要的 AI 入口**（完整模式）。一個目標框＋模式切換：

| 模式 | 幫你什麼 | 會不會扣點 |
|------|----------|------------|
| **問 AI（一起想）** | 發想、拆分鏡、查專案資料、要建議動作 | 文字多半**免費** |
| **直接生成** | 挑模型出圖／影／音；世界觀與勾選卡自動帶 | **扣點**（送出前確認） |
| **製作範本** | 固定多步套路一次串 | 各步依模型扣點 |
| **多步開拍／執行計畫** | 排步驟、估點、核准後背景跑 | 核准後執行才花點 |

| 附屬 | 幫你什麼 |
|------|----------|
| **＋ 請誰來幫忙（技能／職能）** | 用「劇組」方式選能力，不必先背分頁 |
| **本次知識優先** | 這次問答／規劃先讀指定知識 |
| **資源抽屜** | 提示詞庫、生成紀錄、執行軌跡——少在長頁裡找 |

**目標框怎麼按**：一起想＝直接送出提問；直接出圖＝只帶入提示詞，**還要再按生成**；範本＝帶入想法。

## 5. 分鏡・送審・交付 🎬⭐

| 功能 | 幫你什麼 | 何時用 |
|------|----------|--------|
| **分鏡列表** | 一支片的鏡頭骨架與狀態 | 整支結構 |
| **單格工作室** | 改一格的提示詞／模型／版本／配音 | 只修一鏡 |
| **排序 ▲▼** | 決定成片順序與打包鏡號 | 打包前 |
| **加入分鏡** | 把生成成品掛到某一格 | 出圖後 |
| **送審／通過／退回** 👥 | 品質閘門；退回帶原因 | 對外定稿前 |
| **打包 zip** ⭐ | 見 [交付與下載](交付與下載) | 通過後給剪輯 |
| **流程條** | 提示下一步（排→補畫面→配音→送審→包） | 不知道該做啥時 |

## 9. 依「你現在的目標」選功能

| 我的目標 | 優先用 |
|----------|--------|
| 今天做出第一支能剪的片 | 簡易模式 → 拆分鏡 → 出圖 → 打包 |
| 畫風／主角要一致 | 世界觀 chips ＋ 角色／場景卡 → 再生成 |
| AI 要照腳本走 | 知識庫放腳本並釘選 → 問 AI／拆分鏡 |

| 給剪輯師檔案 | 送審通過 → 交付 zip → [交付與下載](交付與下載) |

| 讓 Claude 代操 | MCP 金鑰（接上外部 AI） |
