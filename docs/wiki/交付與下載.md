# 交付與下載

> 做片的最後一哩：把「專案裡通過的內容」變成**剪輯師打得開、檔名對得上**的一包。  
> 讀完你會知道：什麼時候能打包、zip 裡有什麼、該開哪個檔、失敗或找不到包時怎麼辦。

---

## 1. 交付在解決什麼？

若沒有統一打包，常見狀況是：

- 圖在聊天、音檔在雲碟、字幕自己重打  
- 檔名沒鏡號，Premiere 裡對了半小時  
- 組長說「通過了」，剪輯拿到的卻是舊版  

系統的交付目標是：

> **一鍵得到依鏡號排好的媒體＋字幕＋可選時間軸**，並在打包當下記住「這次包了什麼」。

---

## 2. 什麼時候可以打包？

| 條件 | 說明 |
|------|------|
| 專案內有分鏡與成品 | 沒內容的資料夾不會出現在 zip 裡 |
| **送審通過**（有審批流程時） | 交付區通常在「分鏡・交付」；通過後才適合當定稿包 |
| 你有權限看這個專案 | 檢視者也常可下載已有的交付，但未必能改內容 |

**實務**：未通過就打包也可以當「草稿自用」，但**對外上架／精修定稿**請等通過，避免剪輯用到被退回的版本。

---

## 3. 在哪裡按？

1. 打開專案 → 捲到 **「分鏡・交付」**（流程條最後一步多半是打包交付）  
2. 下方 **「交付」** 區 → **打包下載交付包（.zip）**  
3. 進入佇列後會顯示 **排隊中／打包中 N/M 檔・大小**  
4. 完成後出現 **下載** 按鈕（可顯示約略大小）  
5. 內容有更新要再包一次 → **重新打包**

### 長任務小提醒

- 打包可能要**幾分鐘**（影片多、體積大時）  
- **可以關分頁或重整**：進度會接回同一個 job，不必從頭重來  
- 背景分頁也應繼續更新進度；若回來仍像卡住，可重整一次或重新打包  

---

## 4. Zip 裡面有什麼？（資料夾解讀）

有內容的資料夾才會出現。常見結構：

| 資料夾／檔 | 給誰用 | 內容 |
|------------|--------|------|
| **00_鎖定原素材**（若有） | 剪輯／存檔 | 不可改動的原音、開示、配樂等**原封**拷貝 |
| **01_視頻素材** | 剪輯時間軸 | 影片類成品，**依鏡號**排序 |
| **02_旁白音檔** | 音軌 | 逐鏡旁白；檔名鏡號對畫面與字幕 |
| **03_圖像** | 靜幀／參考 | 圖片類成品 |
| **04_字幕** | 剪輯／平台 | `字幕.srt`（剪映／Premiere／YouTube 可匯入） |
| **05_文件** | 對稿／存檔 | 腳本與鏡頭表（每鏡秒數、檔名、提示詞、模型等） |
| **交付/** | **最快上手** | 時間軸與字幕：見下一節 |
| **README.txt** | 所有人 | 資料夾說明與軟體匯入提示 |

> 同一鏡號在「畫面／旁白／字幕」之間對得起來，是這包最有價值的地方——請不要手動打亂檔名再怪對不齊。

---

## 5. 「交付/」資料夾：選對你的軟體

| 你的軟體 | 建議檔 | 怎麼用 |
|----------|--------|--------|
| **Premiere Pro** | `Premiere時間軸.xml` | 匯入 XML；媒體以相對路徑掛載，路徑變了再 relink |
| **Final Cut Pro / DaVinci Resolve / 剪映專業版** | `時間軸.fcpxml` | 匯入 fcpxml；分鏡順序、秒數、旁白軌較省手排 |
| **剪映／CapCut（消費版）** | 見第 6 節「剪映草稿包」或媒體＋srt | 消費版不一定吃專業時間軸，見下 |
| **只要字幕** | `字幕.srt` 或 `04_字幕` | 直接匯入字幕軌 |
| **剪輯表交換** | `剪輯表.edl` | 給部分流程／機房用 |

### 最快組片（推薦順序）

1. 解壓 zip（路徑不要有怪字元較省事）  
2. 開對應軟體 → 匯入 **交付/** 裡的時間軸檔  
3. 若媒體顯示離線 → **重新連結**到解壓後的 `01_`／`02_` 等資料夾  
4. 再調字幕卡點、轉場、配樂 loudness  

---

## 6. 剪映／CapCut 怎麼拿？

| 方式 | 適合 | 做法 |
|------|------|------|
| **剪映草稿包（實驗）** | 想開剪映就看到三軌排好 | 專案交付區 → **進階：只要單檔** → 剪映草稿包；依包內說明放到剪映草稿目錄 |
| **媒體＋字幕手組** | 草稿包不相容你的版本時 | 把 `01_`／`02_`／`03_` 拖進時間軸，再匯入 `字幕.srt` 依鏡號對位 |
| **只要骨架單檔** | 先對秒數、不要大媒體 | 同一「進階」摺疊內的 fcpxml／xml／srt／edl 單檔 |

若草稿包打不開：先確認剪映版本與包內說明的目錄位置；不行就退回「媒體＋srt」，一樣能剪完。

---

## 7. 其他下載入口（別跟交付包搞混）

| 名稱 | 在哪 | 是什麼 |
|------|------|--------|
| **專案交付 zip** | 專案 → 分鏡・交付 | **這一支片**的成品包（上文主軸） |
| **素材庫單檔** | 專案 → 素材庫 | 單一圖／影／音下載或當生成來源 |
| **生成紀錄** | 工作台資源抽屜 | 單次生成結果再下載／再用設定 |
| **資料下載** | 帳號選單 → 資料下載 | 站內**文件／模型說明／政策**等白名單檔，**不是**你的片子 zip |
| **鎖定素材** | 素材庫標記鎖定 | 打包時進 `00_鎖定原素材`，剪輯圍繞它組、不改原檔 |

## 8. 打包前後檢查清單

### 打包前

- [ ] 鏡號順序正確（▲▼ 調過）  
- [ ] 要上架的格子已**通過**（若你們有審批）  
- [ ] 旁白與畫面鏡號一致（有配音的格）  
- [ ] 鎖定原音／配樂有標「鎖定」  
- [ ] 估過 zip 可能很大（多支影片時網路與磁碟要夠）  

### 打包後

- [ ] 能從完成鈕**下載**到本機  
- [ ] 解壓後 README 與 `交付/` 在  
- [ ] 時間軸匯入後鏡數大致正確  
- [ ] 字幕有聲畫大致對得上（再精修卡點）

## 9. 常見問題

**Q：進度一直「排隊中」？**  
A：先等一兩分鐘；可重整頁面接回 job。仍不動再按重新打包。影片很多時佇列本來就較久。

**Q：下載後剪輯裡媒體全灰？**  
A：時間軸用相對路徑。把整個解壓資料夾放一起再 relink，不要只複製 xml 不帶 `01_` 資料夾。

**Q：為什麼沒有 02_旁白？**  
A：沒有旁白成品的資料夾不會出現——先補配音再打包。

**Q：可以只包某幾格素材嗎？**  
A：素材庫若支援多選打包，可只打選中的素材；**全片交付包**仍以分鏡流程為主。

**Q：交付包會過期嗎？**  
A：依站台保存政策；重要上架請在本機與團隊碟各留一份，不要只依賴線上暫存。

**Q：手機上能打包嗎？**  
A：可以排程打包，但**大 zip 建議在電腦下載**較穩；手機可先送審通過，回桌面再下載。

```text
定盤（世界觀／卡／稿）
  → 生成與分鏡
  → 送審通過
  →【本頁】打包下載
  → 剪輯軟體精修與上架
```
