# 場景設定卡

## 是什麼？

**場景設定卡**（程式表 `scene_presets`）是專案的**色板／光線庫**：建一次、生成時勾選，讓同一場景跨分鏡時光影與配色較一致。

與世界觀不同：

| | 世界觀 | 場景設定卡 |
|--|--------|------------|
| 範圍 | 整支片基調 | 某一個場地 |
| 內容 | 故事／主張／調性／畫風 | **色板 + 光線**（可選參考圖） |
| 生成時 | 有填就自動帶 | **要勾選**才注入 |

---

## 卡片欄位

| 欄位 | 程式 | 說明 |
|------|------|------|
| 名稱 | `name` | 場景代號（例：晨光空間、戶外廣場） |
| 色板 | `palette` | 主色／配色（必填，會注入） |
| 光線 | `lighting` | 光源方向、氛圍（可選，會注入） |
| 參考圖 | `referenceAssetId` | 可選；上傳或從素材庫綁定（比對／之後圖生圖） |

UI：專案頁「場景設定卡」；生成／工作台勾選，**最多 4 張**（`scenePresetIds.max(4)`，與 `MAX_GENERATE_SCENE_PRESETS` 對齊）。

---

## 對 AI 生成的幫助

### 圖／影：自動帶「場景錨點」

勾選後，視覺生成 prompt 會附加：

```text
[場景設定] 晨光空間：色板 暖米、琥珀、低飽和、光線 側窗柔光、低對比
```

| 規則 | 說明 |
|------|------|
| **只進視覺** | 文生圖／圖生圖／文生影／圖生影（`CARD_ANCHOR_CATEGORIES`） |
| **不進** | LLM 正文旁白、TTS、配樂等 |
| **順序** | 依勾選 id 順序組裝 |
| **截短** | 色板約 160 字、光線約 120 字（`CARD_FIELD_MAX`／`CARD_LIGHTING_MAX`） |

程式：`buildSceneAnchor` → `formatSceneAnchor` → `withSceneAnchor`（`server/services/cardAnchors.ts`、`generationCore.ts`）。

### 跨鏡一致

同一張卡在多個分鏡都勾 → 模型反覆看到同一套色板／光線，比較不會一鏡暖一鏡冷。

### 知識庫／導演

場景卡會以 `【場景設定卡】` 段落進知識上下文（最多約 12 張，`PRESET_KNOWLEDGE_INJECT_MAX`），助手／導演可讀「專案有哪些場景」。

### 咒語「再用」

提示詞可連同模型／角色／**場景卡**一併存檔；再用時還原完整設定，不只文字。

## 與角色定裝、世界觀分工

| | 世界觀 | 角色定裝 | **場景設定** |
|--|--------|----------|--------------|
| 管什麼 | 故事／主張／調性／風格 | 人物外觀 | **場地色板＋光線** |
| 填寫 | 專案級 | 建角色卡 | 建場景卡 |
| 生成 | 自動（有填就有） | **勾選** | **勾選** |
| 注入標籤 | `[專案背景]` | `[角色定裝]` | `[場景設定]` |

- 世界觀的「敘事人物」≠ 畫面定裝 → 畫面要像請用**角色卡**。  
- 跨鏡光色一致 → 用**場景設定卡**，不要只靠每格 prompt 重打光線。  
- 畫風／調性仍以世界觀 chips 為主（見 [世界觀 Chips 複選與優先序](世界觀-chips-複選與優先序)）。

---

## 怎麼用（檢查清單）

1. 專案頁建卡：名稱 + 色板（建議再填光線；可選參考圖）  
2. 生成或工作台勾選該場景（≤4）  
3. 同場景的分鏡都勾**同一張**  
4. 換場地就換勾另一張  

**不要指望**場景卡取代每格畫面描述；主控仍是當格 prompt。場景卡是**光色偏置**。長劇情放分鏡／腳本，不要把整段故事塞進色板欄。
