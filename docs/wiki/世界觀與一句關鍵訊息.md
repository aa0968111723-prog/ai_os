# 世界觀與一句關鍵訊息

## 一句關鍵訊息是什麼？

**一句關鍵訊息**（程式欄位 `message`）是世界觀快速層的核心欄位之一，定位為 **「一片一訊息」**：這支片要傳達的那句主張，而不是情節本身。

| 欄位 | 程式名 | 角色 | 例子 |
|------|--------|------|------|
| **一句話故事** | `logline` | 情節／畫面：誰、在哪、發生什麼 | 訪客走進安靜的空間、整理思緒… |
| **一句關鍵訊息** | `message` | 主張／重點：觀眾要帶走什麼 | 在安靜裡重新找回自己 |

兩者一起，片才既有**畫面故事**，又有**要傳達的重點**。Schema 見 `shared/worldview.ts`。

---

## 對整個專案的幫助

1. **整片不跑題（主張定盤）**  
   AI 代理、導演、助手規劃時會帶上「核心訊息」，避免只顧分鏡好看、卻偏離「這片到底要說什麼」。`brief` 模式**必含 message**，就是為了守住一片一訊息。

2. **生成時自動當背景錨**  
   文生圖／影、LLM 旁白等會把關鍵訊息注入成 `核心訊息:…`，每格 prompt 不必重講主張。  
   詳見 [世界觀如何注入 AI 生成](世界觀如何注入-AI-生成)。

3. **團隊與交付對齊**  
   組長、組員、AI 共用同一句「我們在傳達什麼」；匯出鏡頭表也會寫進關鍵訊息。

4. **可參與「基調就緒」**  
   `isWorldviewReady`：有 **logline 或 message**，再加上至少一項調性／視覺風格，就算世界觀就緒（onboarding「設世界觀」可打勾）。只填訊息、不填故事也可以過門檻。

**總結**：一句關鍵訊息 = 整支專案的「主張錨」。故事管「發生什麼」，訊息管「為什麼做這支、觀眾記住什麼」。

## 對 AI 生成的幫助

核心作用：**自動當「這片要主張什麼」的背景**，讓 AI 不必只靠當格 prompt 猜主題。填一次後，系統在生成時附上 `核心訊息:…`（寫在 `[專案背景]` 裡）。

### 圖／影生成（中等幫助）

文生圖、圖生圖、文生影、圖生影會注入，例如：

```text
清晨安靜的空間

[專案背景] 調性:…|視覺風格:…|故事錨點:…|核心訊息:在安靜裡重新找回自己
```

| 幫助 | 說明 |
|------|------|
| **主題方向** | 多一點「要傳達什麼」的語彙，畫面較不易只剩空場景 |
| **跨鏡一致** | 每格都帶同一句主張，整支片較不易跑偏 |
| **不取代 prompt** | 擴散模型對長中文主張句通常是**弱錨**；畫風／調性（中英 chips）往往比關鍵訊息更有效 |

實務上：關鍵訊息是「軟偏置」，主控仍是**當格 prompt + 風格／調性**。

### 文字／LLM 生成（較強幫助）

旁白、腳本、文案等 LLM 路徑會注入 `核心訊息`（以及訊息主軸、禁忌等）。

| 幫助 | 說明 |
|------|------|
| **文案對準主張** | 旁白／腳本較會往「一片一訊息」收，而不是只描述畫面 |
| **減少重講** | 不用每段都寫「記得傳達某某」 |
| **與 logline 互補** | 故事錨＝發生什麼；核心訊息＝要說什麼 |

語言模型讀得懂敘事主張，所以這條路比圖影**更有感**。

### 導演／代理／助手（規劃層，很有感）

拆分鏡、代理排程、專案助手使用 brief／director 格式，**一定帶核心訊息**。

| 幫助 | 說明 |
|------|------|
| **規劃不偏題** | 代理解「這片要傳達什麼」，步驟目標較不易偏成純技術或純畫面 |
| **分鏡有主張** | 導演建議鏡頭時，有主張可對齊，而不只排「好看鏡頭」 |
| **合規一併守** | brief 同時帶禁忌，避免規劃踩線 |

### 哪些生成不會用到？

| 類型 | 原因 |
|------|------|
| TTS 旁白 | 避免把「核心訊息:…」唸出來 |
| 配樂／音效 | 敘事句對音頻是雜訊 |
| 轉錄／訓練等 | 不適用 |

### 強度對照

| 消費者 | 關鍵訊息的用處 | 強度 |
|--------|----------------|------|
| **LLM／旁白／腳本** | 對準主張、少跑題 | **高** |
| **導演／代理／助手** | 規劃與分鏡守「一片一訊息」 | **高** |
| **圖／影模型** | 多一點主題語彙當方向 | **中偏低** |
| **風格／調性**（對照） | 畫風一致 | 出圖往往比訊息句更有效 |

---

## 實務建議

- **有要寫旁白、腳本、代理拆片** → 關鍵訊息很值得填，AI 文案與規劃會明顯對準。
- **主要只出圖** → 仍有幫助，但請優先填好**調性＋視覺風格**；關鍵訊息當「主題偏置」即可。
- **不要指望**只靠一句關鍵訊息就出對的圖；每格 prompt 仍要寫清楚畫面。
- 只填 logline 不填 message 仍可開工，但少了「主張定盤」；兩者都填效益最大。

## 工程對照

| 項目 | 位置 |
|------|------|
| Schema／就緒判定 | `shared/worldview.ts`（`message`、`isWorldviewReady`） |
| 視覺注入 | `formatWorldviewVisualPositive` → `核心訊息:…` |
| LLM 注入 | `formatWorldviewForAi(..., "generation-llm")` |
| 代理／助手 brief | `formatWorldviewForAi(..., "brief")`（必含核心訊息） |
| 導演 | `formatWorldviewForAi(..., "director")` |
| 實際拼接 | `server/services/generationCore.ts` → `effectivePromptParts` |
