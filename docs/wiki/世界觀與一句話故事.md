# 世界觀與一句話故事

## 世界觀是什麼？

世界觀是**專案的定盤星**（brief）：填一次，後面生成、導演、代理、交付都共用，減少「每格重講故事」。

結構分兩層（見 `shared/worldview.ts`）：

### 快速層（約 1 分鐘）

| 欄位 | 程式名 | 角色 |
|------|--------|------|
| **一句話故事** | `logline` | 情節／情境：誰、在哪、發生什麼 |
| **一句關鍵訊息** | `message` | 弘法重點：這片要傳達的一句核心 |
| 目標觀眾 | `audience` | 給誰看 |
| 訊息主軸 | `themes` | 敘事弧（苦→修行→轉變…） |
| 調性 | `tones` | 莊嚴、溫暖…（有中英錨點） |
| 視覺風格 | `styles` | 水墨禪意、寫實攝影…（有中英錨點） |

### 進階層（可後補）

三幕（鉤子／轉折／行動呼籲）、敘事人物、參考連結、禁忌事項等。

預設禁忌含醫療宣稱等合規句，生成時視覺類別會走 **negative_prompt**，避免畫成畫面文字。

## 「一句話故事」對專案的幫助

1. **給 AI 敘事錨**  
   生成／規劃／導演都圍著同一句故事，而不是只看當格 prompt。

2. **決定「基調是否就緒」**  
   `isWorldviewReady`：有 logline **或** message，且至少一項調性或視覺風格。  
   Onboarding 第一步「設世界觀」打勾靠這個。

3. **與關鍵訊息分工**  
   - 故事：訪客在晨光禪堂點香…（畫面／情節）  
   - 訊息：把心交還給光（主張）  
   兩者一起，片才既有畫面又有弘法重點。

4. **跨管線共用**  
   圖影生成、LLM、代理、導演、匯出鏡頭表——同一份世界觀。

5. **團隊對齊**  
   組長／組員／AI 對「我們在做哪支片」有共同一句話。

---

## 範例（種子專案風格）

> 一位訪客在晨光禪堂點起一炷香，在陪伴與整理之間，把浮躁的心慢慢交還給平靜。

- **故事（logline）**：情境與畫面方向  
- **訊息（message）**：另欄填「一片一訊息」式核心句  
- **風格／調性**：決定「看起來／感覺像什麼」——出圖時往往比長故事句更有感
