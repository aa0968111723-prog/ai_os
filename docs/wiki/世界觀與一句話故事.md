# 世界觀與一句話故事

## 世界觀是什麼？

世界觀是**專案的定盤星**（creative brief）：填一次，後面生成、導演、代理、交付都共用，減少「每格重講故事」。

結構分兩層（見 `shared/worldview.ts`）：

### 快速層（約 1 分鐘）

| 欄位 | 程式名 | 角色 |
|------|--------|------|
| **一句話故事** | `logline` | 情節／情境：誰、在哪、發生什麼 |
| **一句關鍵訊息** | `message` | 這支片要傳達的核心主張（一句話） |
| 目標觀眾 | `audience` | 給誰看 |
| 訊息主軸 | `themes` | 敘事弧或主題標籤（可自訂） |
| 調性 | `tones` | 莊嚴、溫暖…（內建選項含中英錨點） |
| 視覺風格 | `styles` | 寫實攝影、手繪插畫…（內建選項含中英錨點） |

### 進階層（可後補）

三幕（鉤子／轉折／行動呼籲）、敘事人物、參考連結、禁忌事項等。

預設禁忌可含合規類句（例如醫療宣稱限制）；生成時**視覺**類別會走 **negative_prompt**，避免把禁語畫成畫面文字。

## 「一句話故事」對專案的幫助

1. **給 AI 敘事錨**  
   生成／規劃／導演都圍著同一句故事，而不是只看當格 prompt。

2. **決定「基調是否就緒」**  
   `isWorldviewReady`：有 logline **或** message，且至少一項調性或視覺風格。  
   Onboarding 第一步「設世界觀」打勾靠這個。

3. **與關鍵訊息分工**  
   - **故事（logline）**：情境與畫面方向（例：晨光裡的安靜空間、人物整理思緒）  
   - **訊息（message）**：要傳達的主張或 call-to-action  
   兩者一起，片才既有畫面又有清楚主旨。  
   關鍵訊息對專案與 AI 的詳細說明見 [世界觀與一句關鍵訊息](世界觀與一句關鍵訊息)。

4. **跨管線共用**  
   圖影生成、LLM、代理、導演、匯出鏡頭表——同一份世界觀。

5. **團隊對齊**  
   組長／組員／AI 對「我們在做哪支片」有共同一句話。

## 範例（中性示範）

> 一位訪客走進安靜的工作室，點起一盞燈，在整理與等待之間，把紛亂的念頭慢慢放下。

- **故事（logline）**：情境與畫面方向  
- **訊息（message）**：另欄填「這支片只講一件事」式的核心句  
- **風格／調性**：決定「看起來／感覺像什麼」——出圖時往往比長故事句更有感
