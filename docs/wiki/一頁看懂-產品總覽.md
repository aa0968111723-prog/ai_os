# 一頁看懂 Aios（產品總覽）

站內對應頁：登入後 → 帳號選單 → **怎麼用**（`/help`，標題「一頁看懂整個網站」）。  
本頁是**維基版濃縮**，與 Help 頁對齊；細節以程式與 Help 頁為準。

## 一句話

把「一份腳本」變成「可拖進剪映／Premiere 的素材包」。  
主線：**設世界觀 → 生成畫面／配音 → 排分鏡送審 → 打包下載**。  
AI 會吃專案**世界觀**、勾選的**角色／場景**、**知識庫**（含置頂與本次優先）。

## 六步主線

1. **世界觀** — 故事／關鍵訊息 + 調性・畫風 chips（多選有優先序）  
2. **拆分鏡** — 工作台「問 AI」；可勾本次知識優先  
3. **生成** — 「直接生成」；送出前確認點數  
4. **排順序** — 分鏡列表／單格工作室  
5. **送審** — 組長審；高額可能要成本核准  
6. **打包** — zip（媒體 + 字幕 + 時間軸）

| 區域 | 有什麼 |
|------|--------|

| 其他 | 模型指南、MCP 外部 AI、交付下載、桌面 Companion、整合連接、回饋 |

## 工作台四模式

| 模式 | 用途 | 扣點？ |
|------|------|--------|
| 問 AI | 發想、拆分鏡、查專案 | 文字多走免費 NIM 額度 |
| 直接生成 | 圖／影／音 | 依模型扣點 |
| 製作範本 | 固定步驟串鏈 | 每步扣點 |
| 執行計畫 | AI 職能多步計畫，核准後背景跑 | 生成步扣點 |

## 必懂新知識

- **本次知識優先**：這一次強制先餵勾選的知識；**置頂**是長期優先。  
- **回收桶**：軟刪可還原；不進 AI、不當生成來源；永久刪才清檔；刪檔不退點。  
- **成本審核門檻**：組員高價生成先待核，組長准了才扣點送出。  
- **專案檢視者**：唯讀（可看／留言／下載，不能寫／生成）。  
- **落地**：成品存進 Volume，避免 CDN 過期死連結；警示橫幅＝快備份。  
- **母版系列**：母版一次、每集四格變數開新案。  
- **AI 職能**：標籤不是真人；計畫關頁也繼續。

## 錢與失敗

- 點數 ≈ NT$1／點；送出前確認預估。  
- **失敗自動退點**。  
- 真生成（需 FAL_KEY）；文字助手多不扣站內點（NIM 流量限制另計）。
