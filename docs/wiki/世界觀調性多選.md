**調性**（程式欄位 `tones`）描述這支片的**感覺／氛圍**，不是情節、也不是「要傳達的一句主張」。

| 概念 | 管什麼 |
|------|--------|
| [一句話故事](世界觀與一句話故事) | 發生什麼 |
| [關鍵訊息](世界觀與一句關鍵訊息) | 要主張什麼 |
| **調性**（本頁） | 感覺像什麼（溫暖、莊嚴…） |
| 視覺風格 | 畫面長什麼樣（寫實、插畫…） |

內建選項見 `shared/worldview.ts` 的 `TONE_OPTIONS`（組別可自訂 chips）。

## 多選策略（系統已實作）

**不是「全勾就全塞進模型」。**

| 機制 | 規則 |
|------|------|
| **順序＝優先序** | 陣列第 1 個＝**主要**，其餘＝備選 |
| **UI 軟上限** | 建議 **≤2**（超過只警告，仍可勾） |
| **出圖硬截斷** | 只注入 **前 2 個**（`VISUAL_INJECT_MAX.tones = 2`） |
| **LLM／導演** | 同樣收斂，並可標「主要／備選」 |
| **改主要** | 已選、非主要 → **Shift+點** 或 **連點** 提到第一位 |
| **中英雙語** | 內建調性注入成 `溫暖(warm, gentle)` 等形式，利於圖影模型 |

常數（單一真相）：

- `CHIP_SOFT_MAX.tones = 2`
- `VISUAL_INJECT_MAX.tones = 2`
- `LLM_INJECT_MAX.tones = 2`

程式：`shared/worldview.ts`（`toggleWorldviewChip`、`promoteWorldviewChip`、`formatWorldviewVisualPositive`、`chipSoftWarnings`）。  
UI：專案頁基調區 chips（`ProjectPage`）。

## 會不會被 AI 吃到？

**會**，且出圖時通常比長中文 logline **更有感**（有英文錨）。

範例（視覺生成正向片段之一段）：

```text
[專案背景] 調性:溫暖(warm, gentle)、真誠(sincere, heartfelt)|視覺風格:…|故事錨點:…|核心訊息:…
```

- 只取**前 2 個**調性；第 3 個以後多半不進圖影。
- 也會進代理／導演／助手的 brief，讓語氣一致。
- **基調就緒**需要：logline 或 message，**且**至少一項調性或視覺風格。

詳見 [世界觀如何注入 AI 生成](世界觀如何注入-AI-生成)。

## 使用建議（怎麼選比較好）

### 建議：1～2 個、且不互斥

| 組合 | 何時用 |
|------|--------|
| 溫暖 + 真誠 | 訪談、見證、溫柔敘事 |
| 莊嚴 + 簡約 | 儀式感、克制畫面 |
| 療癒 + 溫暖 | 舒緩、陪伴感 |
| 活潑 + 溫暖 | 活動紀實、輕快但不吵 |

### 較不建議

| 做法 | 原因 |
|------|------|
| 莊嚴 + 活潑 並選 | 氣氛對沖，畫面易「什麼都有、什麼都不像」 |
| 一次勾 4～6 個 | 只前 2 有用，其餘造成「我勾了怎麼沒效」的誤解 |
| 用調性當關鍵訊息 | 調性是感覺；主張請寫在關鍵訊息 |

### 心智模型

- **1 個**＝穩定基調  
- **2 個**＝主 + 副（例如「以溫暖為主，帶一點莊嚴」）  
- **3 個以上**＝幾乎沒幫助（出圖仍只吃前 2）

## 操作（專案頁）

1. 在世界觀快速層點調性 chip 勾選／取消。  
2. 第一個勾選的會成為**主要**（標籤「主要」）。  
3. 要改主要：對已選、非主要的 chip **Shift+點** 或 **連點**。  
4. 超過建議數量時，畫面會出現軟警告（仍可存檔）。

---

## 若再優化產品（可選 backlog）

依 CP 值：

1. UI 更清楚「第 3 個起不進生成」  
2. 互斥提示（如莊嚴↔活潑）  
3. 圖影注入寫成「主要／輔」語（與導演格式對齊）  
4. 拖曳改優先序  

**不建議**改成強制單選（溫暖+真誠等合理組合會變難用），也不建議多選全量注入。
