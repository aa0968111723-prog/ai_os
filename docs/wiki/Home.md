# Aios 使用說明（維基首頁）

**AI Director OS（Aios）**：把腳本變成「可送審、可打包、可進剪輯軟體」的團隊創作作業系統。

本維基以**創作者與組長**為第一讀者：講清楚網站**如何幫你少重做、少卡關、少燒點**。  
（工程實作細節以程式與測試為準；此處不放 PR 進度、Wave 路線圖等內部開發文件。）

---
