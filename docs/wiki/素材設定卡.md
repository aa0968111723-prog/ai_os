# 素材設定卡

## 是什麼？

**素材設定卡**（程式表 `props`）是專案的**道具／物件庫**：反覆出現的東西（紅傘、佛珠、活動主視覺牌）外觀材質建一次、生成時勾選，讓同一件東西跨分鏡不變樣。

這是「角色·場景一致性」缺的第三塊：角色管人、場景管地、素材卡管**物**。

與「素材庫」不同（名字很像，東西完全不同）：

| | 素材庫（`assets`） | 素材設定卡（`props`） |
|--|--------------------|------------------------|
| 是什麼 | 已經存在的**檔案**（上傳／生成的圖影音） | 還沒被畫出來的**物件設定**（文字描述） |
| 用途 | 當生成來源、交付打包 | 注入生成 prompt 當外觀錨點 |
| 位置 | 專案頁「素材庫」 | 專案頁「素材設定」 |

---

## 卡片欄位

| 欄位 | 程式 | 說明 |
|------|------|------|
| 素材名 | `name` | 物件代號（例：紅傘、佛珠） |
| 外觀・材質 | `appearance` | 顏色／材質／尺寸／新舊（必填，會注入） |
| 用途・出現場合 | `notes` | 何時出現、怎麼拿（可選，**不**進畫面） |
| 歸屬 | `ownerKind`／`ownerId` | 可選；掛在某張角色卡（隨身物品）或場景卡（場上物件） |
| 參考圖 | `referenceAssetId` | 可選；上傳或從素材庫綁定（比對／之後圖生圖） |

UI：專案頁「素材設定」；生成／工作台勾選，**最多 4 張**（`propIds.max(4)`，與 `MAX_GENERATE_PROPS` 對齊）。每專案上限 50 張。

---

## 歸屬：這件東西屬於誰

一張素材卡可以是三種身分之一：

| 歸屬 | 例子 | 意思 |
|------|------|------|
| **角色隨身**（`ownerKind="character"`） | 安倢的紅傘、師父的念珠 | 這件東西跟著某個角色走 |
| **場景物件**（`ownerKind="scene"`） | 禪堂的佛龕、廣場的旗桿 | 這件東西固定在某個場地 |
| **獨立物件**（`ownerKind=null`，預設） | 活動主視覺牌 | 誰都不屬於，要用就自己勾 |

歸屬不只是標籤，它有兩個實際效用：

### 1. 勾主人 → 物件自動一起帶入

生成時只要勾了「安倢」，掛在她名下的紅傘、佛珠會**自動被帶進這次生成**——不必記得「畫安倢就要順便勾紅傘」。規則（`shared/propOwnership.ts`，前端預覽與後端注入共用同一支純函式）：

- 順序：先角色、後場景；同一主人下依卡片建立順序
- **明確勾選優先**：上限（4 張）吃緊時被丟掉的是自動帶入的，不是你親手勾的
- 生成台的「素材」chip 會顯示 `素材 3（含隨身 2）`，確認面板也會寫清楚多帶了幾個
- 落庫的 `generations.propIds` 記的是**實際注入的那批**（含自動帶入），重試才還原得回同一組錨點

### 2. 錨點寫成「安倢的紅傘」

有主人的物件，注入時是 `材質鎖定 安倢的紅傘：…` 而不是 `材質鎖定 紅傘：…`——把物件綁在對的人／地上，減少「傘飄到別人手裡」。主人名字會**凍進一致性快照**，之後主人改名或被刪，同一批鏡頭重試出來的錨點仍是當初那句。

主人卡被刪除時，卡片上會顯示「主人卡已刪除」，而且不再被自動帶入——不會靜默裝成獨立物件。

## 對 AI 生成的幫助

### 圖／影：自動帶「素材錨點」

勾選後，視覺生成 prompt 會附加：

```text
[素材設定] 材質鎖定 安倢的紅傘：正紅長柄傘、霧面傘布、木質握把、傘面微舊
```

（沒設歸屬的獨立物件寫成 `材質鎖定 紅傘：…`）

| 規則 | 說明 |
|------|------|
| **只進視覺** | 文生圖／圖生圖／文生影／圖生影（`CARD_ANCHOR_CATEGORIES`） |
| **不進** | LLM 正文旁白、TTS、配樂等 |
| **順序** | 依勾選 id 順序組裝 |
| **截短** | 外觀約 160 字（`CARD_FIELD_MAX`）；用途備註不進畫面 |

程式：`buildPropAnchor` → `formatPropAnchor` → `withPropAnchor`（`server/services/cardAnchors.ts`、`generationCore.ts`）。

注入順序是 `[專案背景]` → `[角色定裝]` → `[場景設定]` → `[素材設定]`：先定基調與人，再定地與物。

### 參考圖當來源

選「圖生圖／參考圖」這類需要來源圖的模型、又沒另外挑來源時，會自動拿卡片上的參考圖當來源。取用順序是**角色 → 場景 → 素材**（道具是配角，有角色／場景圖時以它們為底）。

### 知識庫／導演

素材卡會以 `【素材設定卡】` 段落進知識上下文（最多約 12 張，`PROP_KNOWLEDGE_INJECT_MAX`），助手／導演讀得到「專案有哪些固定道具」。

### AI 代理規劃

多步計畫的 `generate` 步驟可用 `propRefs`（上下文代號 `propN`）指定要帶哪些素材卡，與 `characterRefs`／`scenePresetRefs` 同一套規則。

### 咒語「再用」／製作範本

提示詞庫會連同模型／角色／場景／**素材卡**一併存檔，「再用此設定」還原完整設定；製作範本（工作流）啟動時也沿用生成台的勾選，整條串鏈每個視覺步驟注入同一套錨點。

## 與角色定裝、場景設定分工

| | 角色定裝 | 場景設定 | **素材設定** |
|--|----------|----------|--------------|
| 管什麼 | 人物外觀 | 場地色板＋光線 | **物件外觀＋材質** |
| 生成 | 勾選 | 勾選 | **勾選** |
| 注入標籤 | `[角色定裝]` | `[場景設定]` | `[素材設定]` |
| 單次上限 | 6 | 4 | **4** |

角色身上的隨身物（安倢的紅傘）兩邊都可以寫。建議：**只在一邊寫細節**——道具會單獨出鏡（特寫、空鏡）就開一張素材卡並**掛歸屬到那個角色**（勾人就自動帶傘，兩邊不必各寫一次）；只是順帶提到、不會單獨入鏡，就寫進角色外觀即可。同一件東西兩邊都寫細節會讓描述互相打架。

## 怎麼用（檢查清單）

1. 專案頁「素材設定」建卡：素材名 + 外觀材質（可選用途、參考圖）
2. 跟著某個角色／場景的東西，**設歸屬**——之後勾主人就自動帶入，少一個要記的步驟
3. 沒有主人的獨立物件，生成時自己勾（≤4）
4. 這件道具出現的分鏡都用**同一張卡**
5. 道具改版（換色、換材質）就改卡，不要另建一張同名卡

**不要指望**素材卡取代每格畫面描述；主控仍是當格 prompt。素材卡是**物件偏置**。

## 逐鏡指定（哪一鏡用哪幾張）

專案層的勾選是「這批生成的預設」；真正排片時，每一鏡要用誰、在哪、拿什麼是不同的。
分鏡表每格有一列**逐鏡卡片綁定**：

- **沒指定**（預設）→ 那一格出圖時沿用生成台當下的勾選
- **指定過** → 這一鏡整組以自己的為準。「這鏡不要人」（紅傘特寫）表達得出來，
  全域勾選不會硬塞一個角色進畫面
- AI 拆分鏡時會**順便指派**每一鏡的卡片（用 `char1`／`preset1`／`prop1` 代號，
  解析不到的代號直接丟掉，不會寫入不存在的引用）
- 每格可「先預覽」：不扣點，看這一鏡實際會送出的提示詞與帶入的設定

規則在 `shared/sceneCards.ts`（`resolveSceneCards`），前後端共用。

分鏡表上方另有**文字腳本**：整份分鏡當一份文件讀或改（`shared/storyboardScript.ts`）。
設定卡在文字裡是唯讀標注——改綁定請用分鏡表那一列，靠名字回推卡片太脆弱。
