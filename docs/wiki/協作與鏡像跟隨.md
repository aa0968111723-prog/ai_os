# 協作與鏡像跟隨

## 功能

同一專案可多人同時在線：

- **Presence**：誰在這個專案  
- **游標／編輯區**：對方大致在看哪、編哪  
- **鏡像跟隨**：跟隨端捲動對齊對方焦點（**不是**螢幕串流）

## 精準度（實機雙帳測過）

| 層級 | 表現 |
|------|------|
| 誰在場 | 高 |
| 在哪一區／哪張卡 | 高（唯一錨點 `#sec-*`、`#scene-*` 等） |
| 螢幕高度鎖定 | 中高（協定含 `vy`／`vx`） |
| 像素級 1:1 | 不做；長捲時可能有約數十～百 px 殘差 |

高準度機制摘要：錨點 + 卡內比例 + 視窗比例鎖定 + 巢狀捲動 + 展開 `<details>`（含手機收合）。

## 使用注意

- 點「鏡像跟隨」進入；再點已跟隨的名字會 **取消**（toggle）  
- 雙方版面差很大（手機收合 vs 桌機）時只能粗定位  
- 前端：`client/src/realtime.tsx`；後端轉發：`server/services/realtime.ts`  
- 實機腳本（需帳密環境變數）：`scripts/e2e-ui/verify-collab-mirror.mjs`

## 與世界觀的關係

協作對齊的是**同一專案狀態**；世界觀的一句話故事則讓 **AI 與交付文件**也對齊同一敘事。兩者互補：人跟得上畫面，模型跟得上故事。
