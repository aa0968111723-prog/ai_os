# 世界觀 Chips：複選、優先序與 AI

訊息主軸、調性可複選；**視覺風格為准單選**。若不約束，多選會把 AI 提示詞沖成「一坨標籤」。本頁說明產品規則與工程行為。

## 核心規則

1. **視覺風格＝准單選**：點選即取代為出圖風格；再點唯一已選＝清空。UI 固定顯示「出圖風格：…」。  
2. **主軸／調性＝可複選**；陣列順序＝優先序：index `0`＝**主要**，其餘＝備選。  
3. **上限**：風格硬 **1**（UI 准單選 + 助手套用截斷）；調性／主軸建議 **≤2**（軟警告）。  
4. **硬截斷（注入）**：圖影只吃主要風格 + 前 2 調性；LLM 再加主軸最多 2。  
5. **舊資料多風格**：若專案仍存多個 styles，注入仍只取 `[0]`；UI 提示一鍵「只留主要」或點其他 chip 收斂。  
6. **風格媒材家族**：寫實系／插畫系／3D 若舊資料跨選會警告（准單選後一般不會再疊加）。

| 欄位 | UI | 圖影注入 | LLM 注入 | 導演／代理 |
|------|----|----------|----------|------------|
| 視覺風格 | **准單選**（出圖標） | 前 1 | 前 1 | 主要；舊多選時標備選 + 選項提示 |
| 調性 | 複選 ≤2 | 前 2 | 前 2 | 主要／備選 + 選項提示 |
| 訊息主軸 | 複選 ≤2 | **不注入** | 前 2 | 同上 |

## 使用者怎麼操作

### 視覺風格

- **點**未選 → 設為出圖風格（**取代**先前選擇，不會疊加）。  
- **再點**目前唯一已選 → 取消。  
- 列下永遠顯示：**出圖風格：XXX** 或「尚未設定」。  
- 若看到舊多選：按 **只留「主要」**，或點想要的風格直接收斂。

### 主軸／調性

- **點選**未勾 → 加到尾端（新備選；若原本空則成為主要）。  
- **再點**已勾 → 取消。  
- **改主要**：下方「改主要：…」按鈕，或 **Shift+點** 已選的非主要 chip。  
- 主要 chip 會顯示「主要」標籤。

## AI 會不會反問／引導？

| 能力 | 現況 |
|------|------|
| 讀已填 chips（標主要／出圖） | ✅ |
| 超標時附「選項提示」 | ✅ brief／導演／export |
| 專案助手／代理主動建議收斂 | ✅ 有警告時注入 `worldviewChipGuidanceForAi` |
| 一鍵套用建議 chips | ✅ 助手動作 `apply_worldview_chips`（使用者確認後寫入；風格落地截到 1） |

用法：在專案助手問「幫我定基調／該選什麼風格」→ 助手提議動作 → 按確認即覆寫有列到的欄位。
