# 這個網站如何幫你做片

> 給**創作者與組長**讀的使用說明——不是開發規格。  
> 讀完你應該能回答：我為什麼要用它？卡在哪一步該按哪裡？怎樣少重做、少燒點？

---

## 1. 它解決什麼問題？

沒有這套系統時，一支短影音／短片的常見現實是：

| 痛點 | 實際代價 |
|------|----------|
| 每格提示詞都重打背景、角色、禁忌 | 同一支片前後畫風、人臉飄掉 |
| 腳本、開示稿、素材散在聊天與雲碟 | AI 不知道你已經定稿什麼 |
| 組員做完了，組長不知道要審什麼 | 案子靜靜卡住 |
| 圖、旁白、字幕各做各的，打包靠人工 | 剪輯上手要重排編號、對檔名 |
| 點數與失敗原因看不懂 | 不敢生、生完又重來 |

**這個網站幫你做的，是把「專案上下文」變成 AI 與團隊共用的工作記憶**，並把交付收成**可直接進剪輯軟體的一包**。

一句話：

> **你負責決定「這支片是什麼」與「哪一格過關」；系統負責記住設定、幫你拆／生／排／審／打包，並讓組長看得到卡點。**

## 2. 你真正要做的三件事

| 你做 | 系統幫你 |
|------|----------|
| **定盤**：故事、調性、畫風、禁忌、角色外觀 | 之後每次生成與問 AI **自動帶入**（不必每格重講） |
| **決策**：哪格滿意、要不要重來、送審是否通過 | 顯示進度、待辦、估點、失敗原因（能退點就退） |
| **交付**：下載 zip、進剪映／Premiere | 依鏡號分資料夾、字幕與時間軸骨架 |

其餘「拆分鏡、出圖、配音、排順序、跨專案問進度」都可以讓 AI 或組代理分擔。

## 3. 兩種做片路徑（先選一條）

### A. 簡易模式（新手／一週一集、先求做完）

適合：**第一次用**、專案還沒有分鏡、只想四步走完一支片。

1. **講一句故事**（＋一兩個調性）  
2. **貼腳本 → AI 拆成分鏡**（免費）  
3. **一鍵把缺畫面的格子生出來**（會扣點）  
4. **送審／打包**

完整版的進階卡、多模式工作台都還在，需要時再「切換完整版」。

### B. 完整版（熟手／品質與控管）

適合：要定裝一致、知識庫長稿、多步計畫、審批與協作。

典型節奏：

1. 世界觀 chips 定盤 → 角色／場景卡  
2. 知識庫貼腳本或開示  
3. AI 創作工作台：**一起想／拆分鏡**（免費）→ **直接出圖**（扣點）→ 必要時 **多步開拍**（計畫先核准再執行）  
4. 分鏡排順序 → 送審 → 交付 zip

## 4. 為什麼「填一次世界觀」那麼重要？

世界觀不是裝飾，而是**整支片的共用記憶**。

| 你填的 | 對你的幫助 |
|--------|------------|
| **一句話故事** | AI 拆分鏡、助手、代理較不易跑題；出圖會帶短「故事錨點」當方向 |
| **調性／視覺風格** | 出圖最有效的一致性旋鈕（比長故事句更影響畫面） |
| **關鍵訊息** | 主張不要漂：旁白與腳本建議會往同一句話靠 |
| **禁忌** | 圖影走負向提示；文字 AI 會「避開」——減少重做 |
| **角色定裝／場景卡** | 跨鏡臉與光影一致；勾選才注入，最多同時 6 個角色 |

### 實務建議（省重做）

1. **先 chips 再長文**：調性＋風格定了，再補一句故事。  
2. **外觀寫在角色卡前面**：注入會截短，重要特徵放最前。  
3. **不要指望一句 logline 取代每格提示詞**：它是背景，主控仍是當格你寫的那句。  
4. 詳見：[世界觀與一句話故事](世界觀與一句話故事)、[世界觀如何注入 AI 生成](世界觀如何注入-AI-生成)、[角色定裝卡](角色定裝卡)。

## 5. 知識庫：讓 AI「讀過你的稿」再動手

把開示逐字稿、腳本、見證放進**專案知識庫**，AI 導演／助手／代理會讀；**圖影模型不會整庫灌進去**（避免亂畫字、爆 token）。

對你有用的用法：

| 情境 | 怎麼做 |
|------|--------|
| 固定腳本每週改主題 | 腳本放 knowledge；拆分鏡時優先讀腳本 |
| 某篇最重要 | **釘選**該篇，或工作台勾「本次知識優先」 |
| 怕 AI 漏讀 | 用「預覽 AI 會讀什麼」看實際納入與是否截斷 |
| 已刪的舊稿 | 進回收桶後**不再注入**，不用怕幽靈上下文 |

詳見：[專案知識庫](專案知識庫)。

## 6. 點數：什麼免費、什麼會扣？

| 動作 | 通常 |
|------|------|
| 問 AI、拆分鏡、排多步計畫（文字） | **免費**（走站內文字額度；打滿會提示稍候或換策略） |
| 圖／影／音生成 | **扣站內點**；頂欄鑽石＝你還能生多少 |
| 建立「待核准」計畫 | 建立多半免費；**核准後**才開始花點執行 |
| 生成失敗 | 多數情況**自動退點**（畫面會寫原因） |

### 怎樣少燒點

1. 先用**免費**拆分鏡與問 AI 把結構談定，再批次出圖。  
2. 出圖前對齊風格／角色卡，減少「整支重畫」。  
3. 看頂欄剩餘與確認框**同一套「剩點」**；週／日額度滑上去看。  
4. 影片模型比單張圖貴很多——先用便宜圖模型對構圖，再上影片。

## 7. 團隊怎麼一起用不卡關

| 角色 | 建議職責 |
|------|----------|
| **組員** | 在專案內創作、送審、看退回原因改；私訊對位 |
| **組長** | 審分鏡／生成核准、看作業台「待我裁決」與「誰卡住了」 |
| **任何人** | 頂欄 **「N 在線」** 看誰在；私訊深問細節 |

### 組長每天 3 分鐘

1. 作業台 → **組代理總指揮／待我裁決**：先清卡最久的。  
2. 看 **誰卡住了**（人員任務逾期）— 常是 AI 在等人，不是 AI 壞掉。  
3. 問總指揮：「本週哪個案子該先推？」— 免費、會查證後回答。

### 組員被退回時

- 看退回標籤／理由，**改那一段**，不要整支重拆結構。  
- 私訊附專案連結或標注分鏡，不要只傳截圖沒脈絡。

協作細節：[協作與鏡像跟隨](協作與鏡像跟隨)。

## 8. 從零到交付：一條可照做的路徑

### 8.1 今天第一支片（約 30–90 分鐘，視生成佇列）

1. **今日工作台** → 建立專案（類型＋平台）。  
2. 進專案：若出現**簡易模式**就用它；否則按「切成簡易模式」。  
3. 寫一句故事＋調性 → 貼腳本 → **AI 幫我拆成分鏡（免費）**。  
4. **生成剩下 N 格**（確認估點）→ 等完成（可關頁；完成可推播）。  
5. 送審（有組長時）→ 通過後到交付區 **打包 zip**。  
6. 解壓 → 媒體拖進剪映／Premiere；有「交付」時間軸檔可先試匯入。

### 8.2 每週固定系列（有母版時）

1. 作業台母版系列 → **開新的一集**（只填主題／原句／禁忌／日期）。  
2. 依母版段落結構生成，**不要改母版骨架**。  
3. 送審 → 通過再當定稿對外。  

（組織若有母版 SOP，以組內操作卡為準。）

## 9. 卡住了怎麼辦（對症）

| 現象 | 可能原因 | 你可做的 |
|------|----------|----------|
| 打了字不知按哪 | 目標框要按旁邊的**送出／帶入**；不同模式意義不同 | 一起想＝直接問；出圖＝只帶入提示詞，還要再按生成 |
| 連點存分鏡只存一格 | 需逐格確認執行 | 多顆確認可同時開著，逐一按「執行」；或改用拆分鏡一次建全稿 |
| 畫風飄、人臉變 | 沒勾角色卡／風格 chips | 補定裝＋風格，重要外觀寫前面 |
| AI 像沒讀腳本 | 稿不在知識庫或沒釘選 | 放進知識庫並釘選／本次優先；看注入預覽 |
| 一直「等核准」 | 組長沒看到 | 組長看作業台待裁決；組員私訊＋專案連結 |
| 生成失敗 | 供應商／內容／額度 | 讀錯誤句；失敗多半退點；換模型或改提示 |
| 手機輸入被底欄擋 | 鍵盤＋導覽列 | 點欄位讓畫面捲上；可「安裝成 App」全螢幕較穩 |
| 點數突然變少 | 他人同組額度／週額 | 頂欄滑看週日與最緊一層 |

站內 **「怎麼用」** 頁（`/help`）有 FAQ 與安裝步驟；帳號選單隨時可 **安裝成 App**（橫幅按「稍後」不會關掉這個入口）。

## 10. 建議你「不要」做的事

- 每格重貼整段世界觀長文（讓系統注入即可）。  
- 未定調性／角色就大量出貴價影片模型。  
- 在母版專案上直接當某一集改到面目全非。  
- 用別人帳號「幫忙按核准」（權責與點數會亂）。  
- 把不宜外流的個資貼進知識庫（文字 AI 會送到雲端運算）。

## 12. 一句收束

這不是「又一個聊天機器人網站」，而是：

> **專案級的創作記憶＋審批節奏＋可剪輯交付。**

你把「這支片是誰、什麼調、什麼不能碰」說清楚一次，後面拆、生、審、包才會省力。  
若只記住一件事：**先定盤（世界觀＋卡＋稿），再花錢出圖。**
