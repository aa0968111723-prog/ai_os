# 組代理總指揮 UI 整合（跨專案調度 + 問總指揮）

針對「太散、資訊量有點多」的精簡整合。

## 精確變更（`client/src/pages/Launchpad.tsx`）

### 1. 按鈕文案
```tsx
{plan.isPending ? "規劃中…" : "排調度計畫"}
```
→
```tsx
{plan.isPending ? "規劃中…" : "產生調度計畫"}
```

### 2. Loading Hint
```
「排調度計畫」的入口
```
→
```
「產生調度計畫」的入口
```

### 3. 授權 Hint（大幅縮短）
原本：
```
授權 0 點＝組代理每派出一份子計畫都會停下來等你核准。填了額度它才會在額度內自己核准；
超過的一律停手問你，不會先做了再說。
```
改為：
```
0 點＝每份子計畫都先問你；填了額度才會在額度內自動核准。
```

### 4. 空狀態 Hint（縮短）
原本：
```
還沒有組代理調度計畫。上面填一句目標，它會排出「派工到哪幾個案子、怎麼盯、卡住找誰」的計畫給你核准。
```
改為：
```
還沒有調度計畫。填目標後會排出派工與盯進度的計畫給你核准。
```

### 5. 問總指揮 label
```tsx
<label htmlFor="ta-question" style={{ marginTop: 0 }}>問總指揮</label>
```
→
```tsx
<label htmlFor="ta-question" style={{ marginTop: 0 }}>或直接問總指揮</label>
```

## 測試檔（`Launchpad.teamCard.test.tsx`）
全域替換：
- `"排調度計畫"` → `"產生調度計畫"`
- `getByLabelText("問總指揮")` → `getByLabelText("或直接問總指揮")`

## 效果
兩個區塊變成連續整體面板，資訊量下降，流程清楚（目標 → 授權 → 產生計畫，或直接問）。
