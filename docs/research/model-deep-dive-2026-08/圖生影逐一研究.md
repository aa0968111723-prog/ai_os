## 底層速記（I2V 共通）

```
輸入圖 → VAE encoder → 潛空間首幀條件 latent
文字 prompt → text encoder → cross-attn / joint attn
Spatio-Temporal DiT（或 3D U-Net）在含噪 video latent 上多步去噪
首幀 latent 經 concat / cross-attn / AdaLN 強制時序從該圖展開
VAE decoder → 影片幀
可選：joint audio-video latent 同步去噪（Veo / Kling 2.6+ / Seedance）
```

## 本批交叉發現

### 必須立即修（P0）

| 項 | 變更 |
|----|------|
| Kling 2.6 + v3 I2V | `input()`：`image_url` → **`start_image_url`** |
| allowlist | **+ `fal-ai/veo3.1/image-to-video`**、**+ `fal-ai/framepack`** |
| 單測 | 上述 true；Kling 參數名 regression |

### P0 計價風險

| 問題 | 影響 |
|------|------|
| Kling 2.6/v3、Veo 3.1、Seedance 1.5 **generate_audio default true** | 站內 cost 寫無音價，實際常 2× |
| Veo 預設 duration 8s，估點寫 5 秒 | 估點偏低 |

### P1

| 問題 | 建議 |
|------|------|
| 全站 I2V 未暴露 duration／generate_audio | 進階面板或強制 generate_audio:false 省點 |
| Runway Gen-3 slug verified false | probe 後確認 |
| LTX v0.9.5 deprecated | 考慮換新 LTX-2 端點 |
| Wan 2.6 id 無 fal-ai 前綴 | 與其他一致性檢查 |

### 選擇心法

| 需求 | 首選 |
|------|------|
| 分鏡圖日常批量動起來 | **Wan 2.2 I2V** |
| 對外關鍵鏡頭＋原生音 | **Veo 3.1 I2V**（關音省錢）或 Kling 2.6 |
| 人物會演／情緒 | Hailuo 2.3 Pro |
| 療癒空景微動 | Luma Ray-2 或 Stable Video |
| 最長空景循環 | FramePack |
| 最低成本預覽 | LTX $0.04 或 fast-svd-lcm |
