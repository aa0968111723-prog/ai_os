## 底層速記（所有現代 T2V 共通）

```
原片幀序列 → 3D/時序 VAE 壓成時空 latent
  → Spatio-Temporal DiT（patch = 時間×高×寬）
  → 文字條件（cross-attn 或 joint attn）
  → 解碼成影片

可選：原生音訊（joint audio-video denoising，如 Veo 3.x）
```

| 家族 | 架構重點 | 原生音 | negative 常見 |
|------|----------|--------|----------------|
| **Veo 3.x** | 3D latent diffusion transformer；音畫同步去噪 | 是（48kHz 級） | **有**（本批補 allowlist） |
| **Kling** | 商業 DiT 系；人物／運鏡強 | 2.6/O3 有 | 有（allowlist 已收） |
| **Wan** | 開源 DiT；可 steps/CFG/插幀 | 否（2.x 主線） | 有 |
| **Hailuo** | MiniMax；微表情／表演 | 否 | 無（schema 極瘦） |
| **Seedance** | 字節；含音檔可選 | 1.5/2.0 可 | 無（未見欄位） |
| **LTX / Mochi / CogVideoX / Hunyuan** | 開源預算檔 | 否 | 有 |
| **Sora 2** | OpenAI；長時長 4–20s | 有 | 無 |
| **Luma Ray 2** | Dream Machine | 否 | 無 |
| **PixVerse** | 風格檔 + 可 multi-clip | 可選 | 有 |

站內共通：`input: (p, f) => ({ prompt: p, aspect_ratio: aspect(f) })`  
→ **未送** `duration`／`generate_audio`／`resolution`／`num_frames` → 全吃官方預設。

| 問題 | 影響 |

### P1

| 問題 | 建議 |
|------|------|
| 全站 T2V 只送 aspect_ratio | 暴露 duration、generate_audio、resolution |
| PixVerse 音訊預設 false（與 Veo/Kling 相反） | 文件標清楚 |
| Kling 2.5 verified false | probe 後升 true 或下架 |

### 選擇心法

| 需求 | 首選 |
|------|------|
| 含對白／環境音電影感 | **Veo 3.1**（關音用 Fast/Lite 省） |
| 人物表演／微表情 | Hailuo 2.3 Pro |
| 開源性價比試拍 | **Wan 2.2** 或 **LTX $0.02** |
