## 影片轉影片（V2V）第一批（2026-08）

> 來源：fal llms.txt / OpenAPI 對照站內 V2V 約 28 條。研究卡見後續 `影片轉影片逐一研究.md`。

### 本批發現（P1 為主，無緊急 422）

| 模型 | 問題 | 建議 |
|------|------|------|
| **Topaz Video Upscale** `fal-ai/topaz/upscale/video` | 官方有 `model`（Proteus default + Artemis/Nyx/Gaia/Starlight 系列）、`upscale_factor`（1–4 default 2）、`target_fps`；站內僅 `{video_url}` | 預設補 `model: "Proteus", upscale_factor: 2`；進階面板暴露 model / factor / target_fps |
| **Sync Lipsync v2 Pro** `fal-ai/sync-lipsync/v2/pro` | 官方 required `video_url` + `audio_url` + optional `sync_mode`；站內用 prompt 欄塞 audio_url（hack 可行） | 強化 sourceHint；未來支援獨立 audio 來源或 UI 雙欄；可暴露 sync_mode |
| **RIFE** `fal-ai/rife/video` | 官方有 `num_frames`（1–4 default 1）等；站內僅 `{video_url}` | 可補 `num_frames: 1`；文件標補幀倍率 |
| **BEN2** `fal-ai/ben/v2/video` | required `video_url`；optional `background_color`、`output_format`（mp4/webm） | 站內基本正確；透明背景用 webm |
| **SeedVR2 Video** `fal-ai/seedvr/upscale/video` | `upscale_mode` / `upscale_factor` / `target_resolution` | 站內僅 video_url；P1 暴露 factor 或 target |
| **Bria / VEED 去背系列** | 多種 background_color / codec 選項 | 維持簡化 OK；文件標預設 |
| **LatentSync / MuseTalk** | 同 Sync：video + audio | 同 Sync 的 UX 建議 |

### 架構筆記（簡）
V2V 主流：
- 升頻／補幀：Topaz proprietary、SeedVR2 擴散時序一致、RIFE 光流插幀
- 對嘴：Sync / LatentSync 音訊條件式 latent diffusion 或專用嘴部模型
- 去背：BEN2 / Bria 分割 + 時序平滑

### 建議後續
1. 人工覆蓋 models.ts（I2V P0）後，一併考慮 V2V input 小幅補強
2. 正式寫入 `影片轉影片逐一研究.md` 完整卡
3. generate_audio / dual-source UX 統一策略
