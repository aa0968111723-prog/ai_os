### 底層速記（編輯系）

```
指令編輯 = 條件生成：
  z 從噪聲出發，但交叉／聯合注意力強綁定 image tokens
  + 文字指令（Kontext / Qwen Edit / Seedream 統一架構）

多模態 LLM 編輯（Nano Banana）：
  理解圖+指令 → 直接渲染，非 strength 重繪

身份鎖（PuLID / InstantID）：
  人臉嵌入注入 attention，與 prompt 並行

超分：
  忠實（ESRGAN/Thera/SeedVR）vs 生成式（Clarity/SUPIR/Recraft Creative）
```
