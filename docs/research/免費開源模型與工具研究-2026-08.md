# 免費／開源模型與工具研究（2026-08）

> 問題：**站上還能再加什麼工具，讓使用者免費用、真的幫得上忙，而平台成本又不高？**
> 範圍：免費 API 額度、瀏覽器端推論、CPU 自架、Serverless GPU 自架，四條路線各自的實際成本與適用邊界。
> 方法：對照各供應商 2026 年現行方案頁與第三方實測整理，再與站內現況（`shared/models.ts`、
> `server/services/llmProvider.ts`、`server/services/cloudInference/`、ADR-008）交叉。
> 定位：**研究文件，不含程式變更**。落地項目列在第 6 節，各自可獨立開單。

---

## 1. 三行結論

1. **最大的免費空間在「文字與語音」，不在「圖與影片」。** 站內文字已經走 NVIDIA NIM 免費額度（0 點），
   但掛的是 2024 世代型號；換成 2026 的免費檔（Cerebras / Groq / Google AI Studio）品質直接跳一級，
   而且多接兩家就有了備援——現在 NIM 一掛，全站免費文字功能同時停擺。
2. **語音轉文字是目前唯一「免費額度大到能當生產用」的缺口。** Groq 免費層每天 28,800 秒音訊
   （約 8 小時）跑 Whisper large-v3-turbo。這正好補上路線圖裡卡住的
   「素材知識庫（RAG）：逐字稿來源就緒後啟動」——來源可以現在就就緒，0 點。
3. **圖／影片自架 GPU 省不到錢，建議不要做。** fal 的開源模型端點價格已經貼著原始 GPU 成本：
   Wan 2.2 在 fal 是 $0.04/秒（480p），自架 Wan 在 H100 上約 $0.034–0.042/秒 —— 省下的
   0–15% 不足以支付冷啟動、維運與失敗重試。這一點與 ADR-008 的方向有出入，第 7 節詳述。

## 2. 站內現況盤點

| 面向 | 現況 | 檔案 |
|------|------|------|
| 媒體生成 | 全部走 fal，實價換算點數扣點 | `shared/models.ts` |
| 文字 LLM | NVIDIA NIM 免費額度，站內 **0 點**；代理走 fal 付費檔 | `llmProvider.ts`、`llmPricing.ts` |
| 免費 LLM 型號 | DeepSeek R1、Llama 3.1 405B/70B/8B、Nemotron-4 340B、Qwen2.5 72B、Mistral Large 2 | `models.ts` L1855–1910 |
| 語音轉文字 | 9 個端點全部 fal 付費（Whisper / Wizper / ElevenLabs Scribe），**無免費檔** | `models.ts` L1986–2080 |
| 免費生成 PoC | `cloudInference/` 僅有 beam **mock**；正式環境預設 `none`，未接真 GPU | `cloudInference/provider.ts` |
| 每日免費額度 | 圖片 5 張／日，計數在 **行程記憶體 Map**（多副本／重啟不共享） | `freeGeneration.ts` |
| RAG 知識庫 | 路線圖未勾選，卡在「逐字稿來源就緒後啟動」 | `README.md` |
| 部署 | Railway：CPU $20/vCPU-月、RAM $10/GB-月、egress $0.05/GB、Volume $0.15/GB-月；**無 GPU** | — |

兩個現況值得單獨點名：

- **免費文字的型號已經過時。** Llama 3.1 405B、Nemotron-4 340B、Qwen2.5 72B 都是 2024 年的檔次。
  2026 年同樣免費就拿得到 gpt-oss-120b、GLM-4.7、Gemini 3 Flash 這一級，差距不是一點點。
- **免費額度計數在記憶體裡。** 註解自己寫了「PoC not multi-instance」。任何要對外開放的免費工具，
  額度都得先落到 DB，否則多開一個 replica 免費額度就翻倍，重啟就歸零。

## 3. 四條路線的成本結構

| 路線 | 平台邊際成本 | 使用者體感 | 適合什麼 | 不適合什麼 |
|------|--------------|-----------|----------|-----------|
| A. 免費 API 額度 | **$0**（額度內） | 快、品質好 | 文字、語音轉文字、embedding、草稿圖 | 尖峰量、需要 SLA、機敏資料 |
| B. 瀏覽器端推論 | **$0**，還省 egress | 首次載模型要等；之後離線可用 | 去背、壓縮、抽幀、短音訊轉錄、字幕微調 | 大模型、長影片、手機低階裝置 |
| C. CPU 自架（Railway 現有容器） | $0.027/vCPU-小時 | 慢但穩、資料不出站 | ffmpeg 類確定性處理、小模型、批次背景工作 | 任何要 GPU 的生成 |
| D. Serverless GPU 自架 | $0.69/小時起（RTX 4090）、H100 $1.74/小時 | 有冷啟動 3–5 秒 | 量大且長期穩定的單一工作負載 | 站內目前的量 —— 見第 7 節 |

**egress 是容易被忽略的一筆。** Railway 出流量 $0.05/GB。一支 100 MB 的成品被下載 10 次就是 $0.05；
路線 B 把處理留在瀏覽器，連上傳都免了，這在影片站是實質省錢，不只是省 GPU。

## 4. 免費 API 額度：可用的家數與實際額度

以下為 2026 年各家現行免費層。**額度隨時會改，接之前務必現查一次**，這是這類方案的常態。

| 供應商 | 免費額度 | 型號 | 站內適用 |
|--------|---------|------|---------|
| **Groq** | 20 RPM／2,000 次日；**音訊 28,800 秒/日** | Whisper large-v3 / v3-turbo、Llama 系 | ★ 語音轉文字主力 |
| **Cerebras** | 1M tokens/日、5 RPM、30K TPM | gpt-oss-120b、GLM-4.7 | ★ 長文彙整、腳本規劃 |
| **Google AI Studio** | 1,500 RPD（Flash 檔） | Gemini 3 Flash、3.1 Flash-Lite | ★ 日常文案主力 |
| **NVIDIA NIM** | 40 RPM，無明確總量 | 100+ 開源檔 | 已接，型號待更新 |
| **Cloudflare Workers AI** | 10,000 neurons/日（跨模型共用） | FLUX schnell、Whisper、BGE embedding | ★ embedding + 草稿圖 |
| **OpenRouter `:free`** | 20 RPM；50 次日（付過 $10 後 1,000 次日） | 輪替中的 27+ 檔 | 備援，勿當主力 |
| **Mistral** | 1B tokens/月 | Mistral 系 | 需**選擇加入訓練**才給——見第 8 節 |
| **Hugging Face** | 免費帳號 $0.10/月額度；ZeroGPU 3.5 分鐘/日 | 全 Hub | 只夠 demo，**不可當生產** |

四家併用的價值不只是額度加總，而是**降級鏈**：Google Flash → Cerebras → Groq → NIM → fal 付費檔。
現在只有 NIM 一家，它一掛站內所有 0 點文字功能同時停擺，使用者看到的是「AI 壞了」。

## 5. 具體工具候選（依「真的幫得上使用者」排序）

### ★★★ 逐字稿（語音轉文字）— 站內最大缺口

開示錄音、會議錄音、既有影片，轉成可搜尋、可引用、可餵給 RAG 的文字。這是團隊每天都會用到、
而現在**站上完全沒有免費檔**的功能（9 個端點全部要點數）。

- **免費來源**：Groq 免費層，Whisper large-v3-turbo，每日 8 小時音訊。
- **成本**：$0。超額自動退回站內既有的 fal Whisper 付費檔。
- **加值**：Whisper 輸出帶時間戳，可直接產 `.srt`，接進現有的交付包與剪映／FCPXML 時間軸。
- **注意**：turbo 相對 large-v3 的字錯率只多 0.3%，但解碼層從 32 降到 4，速度快近一倍——
  對中文開示這種長音檔是對的取捨。

### ★★★ 免費文字檔現代化

把 `models.ts` 裡七個 NIM 免費檔換成 2026 世代，並加上第二、三家供應商。

- gpt-oss-120b（Cerebras，2,000+ tokens/秒）取代 Nemotron-4 340B
- GLM-4.7（Cerebras）中文表現優於 Qwen2.5 72B
- Gemini 3 Flash（Google AI Studio）1M 上下文，適合整份逐字稿彙整
- Llama 3.1 405B / Mistral Large 2 可直接下架——同樣是 0 點，沒有理由留舊檔

### ★★★ 瀏覽器端工具箱（transformers.js + WebGPU + ffmpeg.wasm）

平台成本嚴格為 $0，且**檔案不離開使用者的裝置**——對開示素材這種內容，隱私是賣點不是附加。
WebGPU 相對 WASM 有 10–100× 加速，2026 的桌面瀏覽器普遍支援。

| 工具 | 模型／函式庫 | 大小 | 用途 |
|------|-------------|------|------|
| 去背 | RMBG-1.4 / MODNet | ~40 MB | 人物去背做合成、角色卡 |
| 快速轉錄 | Whisper tiny/base | 40 MB 起 | 短片段草稿、對 Groq 額度的補位 |
| 語意搜尋 | mxbai-embed-xsmall | ~30 MB | 素材庫本機搜尋 |
| 影音處理 | ffmpeg.wasm | — | 抽首幀做分鏡縮圖、裁比例、轉檔、燒字幕預覽 |

Hub 上有 1,200+ 個已轉檔可直接用的模型。建議以「工具」而非「模型」的形式呈現在 UI 上——
使用者要的是「幫我去背」，不是「選一個 segmentation model」。

### ★★ RAG 知識庫：pgvector + 免費 embedding

路線圖上唯一因為「來源沒就緒」而卡住的項目，一旦逐字稿通了就能啟動。

- **不需要新的 vector DB。** 現有 Railway Postgres 裝 pgvector 就好：一條連線字串、一套備份、
  一個真相來源。10M 以下向量的量級，pgvector 在 2026 已經追平其他方案，而運維簡單度是碾壓的。
- **embedding 免費**：Cloudflare Workers AI 的 BGE 系列走免費 neurons，或直接在現有容器上跑
  CPU 小模型（30–100 MB 級距，Railway CPU 完全吃得下）。
- 成本落在 DB 儲存（$0.15/GB-月），不在推論。

### ★★ 免費草稿圖額度

生成台的腦力激盪階段本來就該便宜，正式成品才走 fal 旗艦檔。

- Cloudflare Workers AI 的 FLUX schnell 走免費 neurons（10,000/日跨模型共用，實際張數需實測）。
- 或 Pollinations：無金鑰、無註冊、Flux 免費，適合當「試手感」的入口；但**無 SLA、無隱私承諾**，
  只適合公開的、丟得掉的草稿。
- **重要對照**：fal 的 FLUX schnell 是 $0.003/MP。1,000 張草稿 ≈ $3 ≈ NT$93。
  也就是說「免費草稿圖」的真正價值是**讓使用者不必先看到扣點**，不是替平台省錢——
  這個區別會影響要投入多少工程量。

### ★ CPU 側確定性工具（現有容器就能跑）

不需要模型、不會出錯、使用者天天要用：字幕燒錄、響度標準化（EBU R128）、格式轉檔、
縮圖批次、比例裁切、音軌抽取。全部是 ffmpeg，成本是幾秒 CPU。
建議獨立成 worker service，避免和 web 搶 CPU。

| 優先 | 項目 | 工程量 | 平台成本 | 使用者拿到什麼 |
|------|------|--------|---------|---------------|

| P0 | 免費 LLM 型號更新 + 多供應商降級鏈 | 小 | $0 | 免費檔品質跳一級、不再單點故障 |
| P0 | 免費額度計數從記憶體移到 DB | 小 | $0 | 額度是真的，重啟不歸零 |

## 7. 為什麼不建議自架 GPU 跑圖／影片（與 ADR-008 的出入）

ADR-008（2026-07-28，Accepted）選了 Beam Serverless GPU 當免費生成的主要 Provider。
以 2026-08 的價格重算，這個結論在**成本面**已經不成立：

| 項目 | fal（現價） | 自架 GPU | 價差 |
|------|------------|---------|------|
| Wan 2.2 影片 480p | $0.04/秒 | Wan 在 H100 約 $0.034–0.042/秒 | **0 ~ −15%** |
| FLUX schnell 圖 | $0.003/MP | RTX 4090 $0.000192/秒 × 2–3 秒 ≈ $0.0006 | −80%，但絕對值 1,000 張只差 $2.4 |
| LTX Video | $0.02/支（固定價） | 難以做到更低 | 無 |

fal 在開源模型上的定價已經貼著原始 GPU 成本走。省下來的部分要拿去付：冷啟動（3–5 秒）、
模型權重冷載入、失敗重試、版本升級、VRAM 規格追蹤（Wan 2.1 要 40 GB+、HunyuanVideo 要 60 GB+）、
以及一整套 provider 維運。以站內目前的量，**這筆帳是負的**。

ADR-008 仍然成立的部分是它的**架構決定**：`CloudInferenceProvider` 這層抽象是對的，
產品程式碼不直接耦合任何 GPU 供應商也是對的。建議保留介面、保留 mock，
但把「免費生成」的實作從自架 GPU 改成**免費 API 額度 + 瀏覽器端 + fal 低價檔**的組合，
等到某個單一工作負載的量真的大到讓 GPU 小時數跑滿，再回頭啟用 Beam adapter。

Beam 若日後要用，數字是：$30/月免費額度、無訂閱門檻、RTX 4090 $0.000192/秒、A10G $0.000292/秒、
H100 $1.74/小時、可 scale-to-zero。以免費圖片額度 5 張/日 × 100 人 × 30 天 = 15,000 張估，
Beam 約 $9/月、fal schnell 約 $45/月——差 $36，不值得為此維護一套 GPU 基礎設施。

**另外：Railway 沒有 GPU。** 走自架路線等於引入第二個雲供應商與第二套維運，這個隱性成本要計入。

## 8. 風險與合規（接之前一定要看）

1. **免費常常等於「你的提示詞拿去訓練」。** Google 在 EU/UK/EEA 以外會用你的提示詞改進模型；
   Mistral 的 1B tokens/月要**主動選擇加入訓練**才拿得到。Groq、Cerebras 一般不訓練。
   → **開示逐字稿、未公開腳本、內部素材不該進會訓練的免費層。** 建議在模型目錄上標「會訓練／不會訓練」，
   跟現有的 `verified` 欄位同一個位置，讓組長選得出來。
2. **商用限制不看會踩雷。** Google 條款禁止高量商業使用；Azure 商用要付費訂閱。
   站內是團隊生產用途，不是個人實驗——這條要認真讀。
3. **模型授權跟自不自架無關。** MusicGen 是 CC BY-NC，**輸出不可商用，自架也一樣違約**。
   若要做配樂／音效，選 Apache 2.0 的 YuE 或 ACE-Step，或 Stable Audio Open
   （Stability 社群授權，營收門檻內可商用）。這條直接對應站內「環境音／配樂」功能。
4. **額度會變。** Cerebras 的免費目錄在 2026-05-31 曾從約十來個模型縮到兩個。
   OpenRouter 的 `:free` 名單「27+」是快照不是定值。
   → 建議把每一份依賴的條款存一份帶日期的副本，**每季重查**；並且免費檔一律要有付費降級路徑。
5. **不要拿 HF ZeroGPU 當生產。** 免費帳號每日 3.5 分鐘 H200、最多 2 個 Space。做 demo 可以，
   撐站內流量不可能。
6. **免費層沒有 SLA。** 凡是走免費額度的功能，UI 要誠實標示，並且失敗要能一鍵轉付費檔——
   站內既有的「已自動備援」標示（`llmProvider.ts` 的 `fellBack`）就是對的做法，沿用它。

## 9. 明確不建議

| 不做 | 理由 |
|------|------|
| 自架 GPU 跑圖／影片生成 | fal 開源檔已貼著 GPU 成本，價差 0–15%，不足以付維運 |
| MusicGen 做配樂 | CC BY-NC，輸出商用違約，自架無解 |
| 在 Railway 主容器跑 Whisper large | 無 GPU；CPU 跑會和 web 搶資源，且 $20/vCPU-月不划算 |
| HF ZeroGPU 當生產推論 | 3.5 分鐘/日 |
| 只接一家免費供應商 | 現況即是——NIM 一掛，全站 0 點文字功能同時停擺 |
| 免費額度計數留在記憶體 | 多副本翻倍、重啟歸零，額度形同虛設 |
