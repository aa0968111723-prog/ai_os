# 個人整合連接（Google 雲端／Notion／外部資料庫）

回應需求「能否讓他們自己連他們自己的 Google 雲端和 Notion 還有自己的資料庫系統？」——可以。
「整合連接」頁（使用者選單 → 工作 → 整合連接，路徑 `/integrations`）讓**每位使用者自己連自己的**外部服務，
連上後在資料庫頁匯入私有內容就像貼公開連結一樣：

| 整合 | 使用者要做什麼 | 連上後的效果 |
| --- | --- | --- |
| **Google 雲端硬碟** | 點「連結 Google 雲端」走 OAuth（只授權**讀取**） | 資料庫「從網址匯入」貼**私有**的文件／試算表／簡報／雲端檔連結即可匯入，不必再設「任何人知道連結都能檢視」；「重新整理」重抓也走自己的授權 |
| **Notion（個人 token）** | notion.so/my-integrations 建整合 → 貼 Internal Integration Secret → 把頁面 Connections 給該整合 | 貼自己的 Notion 頁面連結即可匯入；沒設個人 token 時退回站方共用 `NOTION_TOKEN`（若有） |
| **外部資料庫／API** | 登記「名稱＋基底網址＋認證標頭」（Airtable、Supabase、自建服務……任何回 JSON/CSV 的 https 端點） | 資料庫「匯入資料」面板出現「從外部連接抓」——選連接、填路徑、一鍵抓取直接進匯入流程；整合頁另有「測試抓取」除錯 |

## 站方一次性設定（管理員）

- **Google 雲端**：與日曆同一組 GCP 憑證（`GOOGLE_CLIENT_ID`／`GOOGLE_CLIENT_SECRET`／`APP_URL`），另需：
  1. GCP「API 程式庫」啟用 **Google Drive API**；
  2. OAuth 憑證的「已授權的重新導向 URI」**再加一條** `{APP_URL}/api/integrations/google-drive/callback`
     （日曆的 callback 是另一條，兩條並存）；
  3. OAuth 同意畫面範圍加入 `.../auth/drive.readonly`——屬敏感範圍：對外發布需 Google 審核，
     **內部（Internal）類型或測試模式**（把夥伴 Gmail 加入測試使用者）則免審即可用。
  未設定時整合頁會顯示「站方尚未設定」，其他整合（Notion／外部 API）不受影響、隨時可用。
- **`INTEGRATION_TOKEN_SECRET`（選）**：憑證加密金鑰種子。未設時系統在 Volume 自動產生持久金鑰檔
  `.integration-key`（0600）——**換 Volume／搬家時記得一併搬**，否則既存憑證解不開（使用者重新連結即可復原）。
  設定環境變數後優先採用、可獨立輪替（輪替後既存憑證同樣需重新連結）。

## 資安設計（配合「強化資訊安全系統」要求）

1. **憑證加密存放**：refresh token／Notion token／API 金鑰一律 **AES-256-GCM** 加密落庫
   （`user_integrations.secret_enc`，iv:tag:cipher）；金鑰種子在環境變數或 Volume 金鑰檔，
   **與資料庫分離——DB 外洩拿不到可用憑證**。加密與 OAuth state 簽章用不同分域派生，跨用途不可互換。
2. **憑證永不回顯**：列表只回 email／workspace／金鑰末四碼；沒有任何 API 會回傳原文或密文。
3. **OAuth 防護**：state 帶 HMAC 簽章＋10 分鐘效期＋`timingSafeEqual`，callback 再比對登入者——
   防 CSRF、防把授權綁到別人帳上；scope 最小化（`drive.readonly` 只讀）。
4. **外部 API 抓取的防外洩設計**：
   - 基底網址限 **https**（憑證不走明文）、建立與抓取時都過 SSRF 守衛（字面快篩＋DNS 解析逐 IP 判私網段）；
   - 抓取路徑強制與基底網址**同源**——`path` 塞 `//evil.com/x` 或絕對網址都會被擋，憑證絕不送去別的主機；
   - **不跟隨重導向**（302 換主機＝把憑證外送的經典手法）；
   - 認證標頭名白名單格式、金鑰值擋換行（標頭注入）；Host/Cookie 等危險標頭不可用；
   - 25MB／25 秒抓取上限、每人每分鐘 20 次節流、每人 10 條連接上限。
5. **審計**：設定／移除／抓取都進 `audit_log`（token 類輸入鍵自動剔除不落明文）；
   Express OAuth callback 亦手動補記 `integrations.googleDriveConnect`。
6. **隔離與撤銷**：連線綁個人（只能看見、使用、刪除自己的）；中斷 Google 連結時盡力向 Google 撤銷授權；
   授權失效（invalid_grant／解密失敗）標記 error 引導重連，不對死憑證重打。

## 已知限制

- Google 匯入的格式與公開路徑相同（文件→txt、試算表→csv、簡報→txt、一般檔案原格式）；
  25MB 上限沿用網址匯入。
- 外部 API 僅支援「拉取（GET）」進匯入流程；反向「本系統資料推出去」請用既有 REST API v1
  ＋個人連線金鑰（見資料庫頁「連接本機／手機／其他系統」）。
- 部署在有出口代理（`HTTPS_PROXY`）的環境時，DNS 層 SSRF 檢查交由代理負責（與網址匯入同口徑）。

## Adobe 帳號（修圖／剪輯，#224 PR1–PR3）

同一頁再多一張卡：使用者連結**自己的 Adobe 帳號**後，AI 可直接在該帳號內做去背、調色等修圖並備妥剪輯素材，
少掉「下載 → 上傳 → 再下載」的來回。素材與成品都留在使用者自己的 Adobe 帳號裡。

- **模式**：`ADOBE_MODE=mock`（預設）不需要任何憑證也不出網，連結／狀態／送工作／輪詢／中斷整條流程照跑；
  申請到憑證後設 `ADOBE_MODE=real` 切換，前端與資料流不需更動。
- **站方設定（real 模式）**：`ADOBE_CLIENT_ID`／`ADOBE_CLIENT_SECRET`／`ADOBE_REDIRECT_URI`
  （未設 redirect 則由 `APP_URL` 推導 `{APP_URL}/api/integrations/adobe/callback`，需在 Adobe Developer Console 逐字登記）。
  未設定時卡片顯示「站方尚未設定」，模擬模式不受影響。
- **憑證保管**：access／refresh token 皆 AES-256-GCM 加密落庫（`external_accounts`），
  金鑰沿用 `INTEGRATION_TOKEN_SECRET` 種子的分域派生（`adobe-token:`／`adobe-state:`）——
  與 Google／Notion 的密文互不可解；原文永不回傳前端。access token 到期前 5 分鐘自動換新。
- **防護**：OAuth state 同樣是 HMAC 簽章＋10 分鐘效期＋`timingSafeEqual`＋callback 比對登入者；
  送工作每人每分鐘 12 次節流；授權失效或解密失敗即標記 error 引導重新連結；
  連結建立時的模式與現行模式不同（mock↔real 切換）視為需重新連結，不會拿模擬憑證去打 Adobe。
- **審計**：`adobe.connect`（Express callback 手動補記）／`adobe.disconnect`／`adobe.editPhoto`／`adobe.renderTimeline`。
- **目前限制（real 模式）**：只接了去背與自動調色；裁切／縮放／微調、素材瀏覽、時間軸算圖回明確的
  「尚未支援」而非猜測請求，`adobe.status` 的 `capabilities` 誠實回報，UI 不顯示做不到的按鈕。
  詳見 `docs/product/adobe-account-linking-pr-roadmap.md`。

## 深度／CUTOS／Aios_b（系統級夥伴，不是個人雲端）

這條不是「使用者連自己的雲端」，而是 **Aios 與兩套作業系統、以及姊妹檢測倉** 的契約：

| 夥伴 | 是什麼 | Aios 怎麼認 | Sentinel 怎麼掃 |
| --- | --- | --- | --- |
| **深度**（Deepin／統信 UOS） | 桌面 WebView 載同一個 Aios 站 | UA 帶 `AiosDeepin/1.0` 或 `Deepin/`／`UOS` | 對應桌面端人格（`AIOS_DESKTOP_TARGET`） |
| **CUTOS** | 邊緣 Node 把 Aios 當 LWA 部署 | UA 帶 `AiosCutos/1.0` 或 `CUTOS` | 對應網站端人格（`AIOS_WEB_TARGET`） |
| **Aios_b** | [Aios Sentinel](https://github.com/aa0968111723-prog/Aios_b) | `AIOS_B_REPO` 或隔壁目錄 | `npm run sentinel` 從本倉呼叫 |

公開握手：`GET /api/os-partners`（只回契約與「有沒有連」，不回網址）。管理頁「深度／CUTOS／Aios_b」卡給開發者看狀態。完整契約見 [os-partner-aios-b-link.md](product/os-partner-aios-b-link.md)。
