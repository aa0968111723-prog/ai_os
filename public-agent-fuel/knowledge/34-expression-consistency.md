# Expression Consistency Techniques

## Goal
Same face + different emotion = still the same person.

## Three Layers
1. Lock base face (Identity Block + reference)
2. Describe expression with visible muscle actions (not abstract emotion words)
3. Explicitly require facial proportions unchanged

## Abstract → Visible

| Abstract | Visible |
|----------|--------|
| Happy | eyes curved into crescents, mouth open smile, cheeks raised |
| Surprised | eyes wide, brows high, mouth O-shaped |
| Determined | brows slightly furrowed, steady gaze, lips pressed |
| Worried | inner brows up, eyes slightly wide, biting lip |

## Template Fragment
```
[Identity] exact same character from reference — [anchors]
[Expression] eyes curved into crescents, mouth open laughing, cheeks raised,
             keep exact facial proportions and face shape from reference
[Negative] different face, changed eye shape, changed facial proportions
```
