# Character Consistency Advanced

## Five Layers
1. Identity Block (verbatim every shot)
2. Reference image dual lock
3. Outfit and accessories inside Identity (not only in Action)
4. Targeted negatives: different face, changed hairstyle, different outfit, older, younger
5. Cross-shot copy-paste of Identity + Style (never “same as above”)

## Multi-Character
Each character gets a full independent Identity block + explicit left/right/center positions + named interaction verbs.

## Agent Checklist
- [ ] Identity first and complete
- [ ] Reference asset bound
- [ ] Outfit inside Identity
- [ ] Negatives cover face/hair/outfit/age
- [ ] Sequential shots copy Identity verbatim
- [ ] Multi-character: separate identities
