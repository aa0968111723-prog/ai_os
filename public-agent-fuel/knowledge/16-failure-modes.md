# Failure Modes Quick Reference

| Symptom | Fix |
|---------|-----|
| Face drift | Longer anchors + exact same + front of prompt |
| Style drift | Repeat style + negatives |
| Character merge | Separate full identities |
| Flat emotion | Body language + light |
| Bad composition | Explicit left/right/center |
| Shot-to-shot inconsistency | Copy identity verbatim |
