# Multi-Character Same-Scene Prompting

## Rules
1. Each character gets a full independent Identity block with name.
2. Write all identities first, then interaction, then scene.
3. Specify relative positions (left / right / center / foreground).
4. Use clear interaction verbs.

## Template
Exact same [A] from reference — [anchors]. Exact same [B] from reference — [anchors].
[A] on the left, [B] on the right, [interaction].
Scene: [...]. 手繪插畫風格, 溫暖活潑簡約, 16:9 cinematic.

## Agent checklist
- Separate identities?
- Positions clear?
- No vague "they"?
