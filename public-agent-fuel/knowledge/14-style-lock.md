# Style Lock & Transfer

Recommended lock level 3-4:
- Style phrase at start AND end
- Negative: photorealistic, 3d render, realistic photo, dark gloomy
- Fixed project phrase: 手繪插畫風格, 溫暖活潑簡約, 乾淨線條, 16:9 cinematic

When transferring style, describe line, color, shadow, temperature first, then content.
